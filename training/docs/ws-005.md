### 集中管理(Windows Admin Center)
1. サーバ管理基盤　>　管理ツール　>　Windows Admin Center
Windows Server 2022 運用　No.5　／　1. サーバ管理基盤
扱う対象と前提
サーバーの土台となる管理基盤。
エディション・役割/機能・管理ツール・初期構成など、以降のすべての役割運用の前提を扱う分類です。
ブラウザベースでサーバー/クラスター/HCIを管理する無償ツール。
前提
・該当する役割/機能をサーバーマネージャーまたは Install-WindowsFeature で導入済みであること。
・操作は原則 PowerShell（管理者）で実行。GUIツールがある場合は併記。
