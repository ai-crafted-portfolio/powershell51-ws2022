# Remove-IpamCustomValue

## SYNOPSIS
Removes a custom value from IPAM.

## SYNTAX

```
Remove-IpamCustomValue [-Name] <String> [-Value] <String> [-Force] [-PassThru] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Remove-IpamCustomValue** cmdlet removes a set of values from a multivalued custom field.
Specify the *Name* parameter and the *Value* parameter.
If you specify values that do not exist in the custom field, the cmdlet removes the values that do exist and returns an error that specifies the values that it did not remove because the values do not exist.
You cannot remove custom values that are assigned to IPAM objects.
You cannot remove built-in values for built-in custom fields.

## EXAMPLES

### Example 1: Remove a value from a custom field
```
PS C:\> Remove-IpamCustomValue -Name "Building" -Value "Main01"
Confirm

This command will permanently delete Custom Value Main01 of Custom Field Building from IPAM. Do you want to

continue?

[Y] Yes  [N] No  [S] Suspend  [?] Help (default is "Y"): Y
```

This command removes the value named Main01 from the custom field named Building.
