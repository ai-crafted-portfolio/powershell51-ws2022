# Stop-SbecLogSession

## SYNOPSIS
Stops a log session.

## SYNTAX

### Object
```
Stop-SbecLogSession -Session <TraceSessionInfo[]> [<CommonParameters>]
```

### Name
```
Stop-SbecLogSession -Name <String[]> [<CommonParameters>]
```

## DESCRIPTION
