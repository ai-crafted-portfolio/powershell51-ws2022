削除ネットワークコントローラーVirtualSubnet

このcmdletは仮想ネットワークから仮想サブネットを削除します.

SYNTAX

Remove-NetworkControllerVirtualSubnet [-VirtualNetworkId] <String> [-ResourceId] <String> [[-Etag] <String>]
 [-Force] -ConnectionUri <Uri> [-CertificateThumbprint <String>] [-Credential <PSCredential>]
 [-PassInnerException] [-WhatIf] [-Confirm] [<CommonParameters>]

このcmdletは,仮想ネットワークから仮想サブネットを削除します.

例えは,

例1

この例では,vnet1という仮想ネットワークからSubnet1という仮想サブネットを削除します.

Remove-NetworkControllervirtualSubnet -ConnectionUri https://networkcontroller -VirtualNetworkId vnet1 -ResourceId Subnet1

# Remove-NetworkControllerVirtualSubnet

## SYNOPSIS

This cmdlet removes a virtual subnet from a virtual network

## SYNTAX

```
Remove-NetworkControllerVirtualSubnet [-VirtualNetworkId] <String> [-ResourceId] <String> [[-Etag] <String>]
 [-Force] -ConnectionUri <Uri> [-CertificateThumbprint <String>] [-Credential <PSCredential>]
 [-PassInnerException] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

This cmdlet removes a virtual subnet from a virtual network.

## EXAMPLES

### Example 1

This example removes a virtual subnet named Subnet1 from a virtual network named vnet1.

```
Remove-NetworkControllervirtualSubnet -ConnectionUri https://networkcontroller -VirtualNetworkId vnet1 -ResourceId Subnet1
```
