# Enable-BCLocal

## SYNOPSIS
Enables the BranchCache service in local caching mode.

## SYNTAX

```
Enable-BCLocal [-Force] [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
The **Enable-BCLocal** cmdlet enables the BranchCache service in local caching mode.
In local caching mode, a client stores data in the BranchCache cache, and attempts to read data from the local BranchCache cache, but does not contact peers and does not attempt to contact a hosted cache server.

## EXAMPLES

### Example 1: Enable BranchCache in local caching mode
```
PS C:\> Enable-BCLocal
```

This command enables BranchCache and configures BranchCache to use local caching mode.
