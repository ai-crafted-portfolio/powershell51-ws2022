記述 Set-AdfsProperties cmdlet は,アクティブディレクトリ連邦サービス (AD FS) のグローバル行動を制御するプロパティを設定しています.

例えは

例1: ADFS 属性を設定する```

PS C:> $Timespan = New-TimeSpan -Minutes 60 PS C:> Set-AdfsProperties -EnableExtranetLockout $True -ExtranetLockoutThreshold 4 -ExtranetObservationWindow $Timespan


最初のコマンドは,TimsSpan**オブジェクトを作成し,結果を$Timespanという変数に保存します.

2番目のコマンドは,ロックアウト前に最大4回の悪パスワード試行先を設定するエクストラネットロックアウトアルゴリズムを設定します.また,コマンドは$Timespan変数に保存されている値の観測ウィンドウを設定します.

-ExtendedProtectionTokenCheck 連邦サーバーがサポートする認証のための拡張保護のレベルを指定します.拡張認証保護は,攻撃者がクライアントの認証情報を傍受してサーバーに送信する中間人 (MITM) 攻撃から保護するのに役立ちます.そのような攻撃に対する保護は,クライアントとの通信を確立する際にサーバーが要求したり,許可したり,要求したりしないようなチャンネル結合トークン (CBT) によって可能になります.

このパラメータの受け入れられる値は:

-要求する.サーバーが完全に硬化され,拡張保護が適用される - 許可する.サーバーが部分的に硬化され,拡張保護が適用される - 対応するためにシステムにパッチが付いた場合 - 適用されない.サーバーが脆弱性があり,拡張保護が適用されない

デフォルト設定は Allow.

Sets the properties that control global behaviors in AD FS.

## DESCRIPTION
The **Set-AdfsProperties** cmdlet sets the properties that control global behaviors in Active Directory Federation Services (AD FS).

## EXAMPLES

### Example 1: Set the ADFS properties
```
PS C:\> $Timespan = New-TimeSpan -Minutes 60
PS C:\> Set-AdfsProperties -EnableExtranetLockout $True -ExtranetLockoutThreshold 4 -ExtranetObservationWindow $Timespan
```

The first command creates a **TimsSpan** object and stores the result in the variable named $Timespan.

The second command sets an extranet lockout algorithm with a threshold of 4 max bad password attempts before lockout.
The command also sets the observation window for the value stored in the $Timespan variable.
