 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Add-BgpRouteAggregate** cmdlet adds a new aggregate route for specific Border Gateway Protocol (BGP) routes.
