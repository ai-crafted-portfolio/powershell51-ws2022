ネットワークコントローラー モジュール

この参照の説明では,すべてのネットワークコントローラー cmdlet の cmdlet の説明と構文が提供されています.

ネットワークコントローラー Cmdlets

Add-NetworkControllerNode は,既存のネットワークコントローラ部署にネットワークコントローラノードを追加します.

Clear-NetworkControllerNodeContent は,ネットワークコントローラーノードからネットワークコントローラー設定をクリアします.

Disable-NetworkControllerNode メンテナンス目的でネットワークコントローラーノードを無効にする.

Enable-NetworkControllerNode ネットワークコントローラーノードを有効にする.

Get-NetworkController はネットワークコントローラーアプリケーションの設定を入手します.

Get-NetworkControllerAccessControlList ネットワークコントローラへのアクセス制御リストを取得します.

Get-NetworkControllerAccessControlListRule ネットワークコントローラによるアクセス制御リストからルールを取得します.

Get-NetworkControllerAuditingSettingsConfiguration は,ネットワークコントローラ用のファイアウォール監査設定を取得します.

[Get-NetworkControllerBackup] (Get-NetworkControllerBackup.md) はバックアップ操作のステータスを取得します.

[Get-NetworkControllerCluster] (Get-NetworkControllerCluster.md) は,ネットワークコントローラークラスター設定を入手します.

Get-NetworkControllerConnectivityCheck はネットワークコントローラー接続性のチェックを入手します.

Get-NetworkControllerConnectivityCheckResult はネットワークコントローラー接続性チェック結果を取得しています.

[Get-NetworkControllerCredential] (※Get-NetworkControllerCredential.md) は,ネットワークコントローラから指定されたデバイス認証またはすべてのデバイス認証を取得します.

Get-NetworkControllerDiagnostic はネットワークコントローラー診断設定を入手します.

Get-NetworkControllerDiscovery は,ネットワークコントローラバージョンとコントローラによってサポートされているURIのバージョンを入手します.

Get-NetworkControllerFabricRoute は,論理ネットワークオブジェクトの論理サブネット子に指定された経路を取得します.

Get-NetworkControllerGateway は,ゲートウェイの1つまたは複数の仮想マシンの設定を取得します.

Get-NetworkControllerGatewayPool は,ゲートウェイプール1つまたは複数のセットアップを設定します.

Get-NetworkControllerIDnsServerConfiguration は,ネットワークコントローラのためにiDNSサーバーの構成オブジェクトを取得します.

Get-NetworkControllerInternalResourceInstances インスタンスのIDのマッピングをRESTのリソースIDに返します.

Get-NetworkControllerIpPool は,ネットワークコントローラからIPプールの設定を回収します.

Get-NetworkControllerIpReservation は,ネットワークコントローラ内のサブセットのIP予約を取得します.

Get-NetworkControllerLoadBalancer は,ネットワークコントローラからロードバランサーリソースの構成を回収します.

Get-NetworkControllerLoadBalancerBackendAddressPool は,ロードバランサーに関連したバックエンドアドレスプール設定を回収します.

Get-NetworkControllerLoadBalancerConfiguration は,ネットワークコントローラからロードバランサーの構成を回収します.

Get-NetworkControllerLoadBalancerFrontendIpConfiguration は,ネットワークコントローラからロードバランサーリソースのフロントエンドIP設定を回収します.

Get-NetworkControllerLoadBalancerInboundNatRule 負荷バランスリソースに関連したインバウンドNATルールを回収します.

Get-NetworkControllerLoadBalancerMux は,ネットワークコントローラが管理するロードバランサーVMの構成を回収します.

Get-NetworkControllerLoadBalancerOutboundNatRule は,ロードバランサーリソースに関連したアウトボウンドNATルールを回収します.

Get-NetworkControllerLoadBalancerProbe は,ロードバランサーリソースに関連した健康探査を回収します.

Get-NetworkControllerLoadBalancingRule は,ロードバランサーに関連したロードバランスルールを回収します.

Get-NetworkControllerLogicalNetwork は,ネットワークコントローラで論理ネットワークの設定を取得します.

Get-NetworkControllerLogicalSubnet は,ネットワークコントローラで論理サブネットの設定を取得します.

[Get-NetworkControllerMacPool] (Get-NetworkControllerMacPool.md) は,ネットワークコントローラからMACプールのプロパティを回収します.

Get-NetworkControllerNetworkInterface は,ネットワークコントローラからネットワークインターフェースの設定を回収します.

Get-NetworkControllerNetworkInterfaceIpConfiguration は,ネットワークコントローラからネットワークインターフェースのIP設定を回収します.

Get-NetworkControllerNode は,ネットワークコントローラーノード設定を入手します.

Get-NetworkControllerPublicIpAddress は,ネットワークコントローラから公開IPアドレスリソースを回収します.

[Get-NetworkControllerRestore] (Get-NetworkControllerRestore.md) は,ネットワークコントローラーデータベース復元オブジェクトを取得します.

Get-NetworkControllerRoute は,ネットワークコントローラ内の特定のルート表からルートを取得します.

Get-NetworkControllerRouteTable は,ネットワークコントローラからルートテーブルの設定を回収します.

[Get-NetworkControllerServer] (Get-NetworkControllerServer.md) は,ネットワークコントローラから物理的なホストの構成を取得します.

Get-NetworkControllerServerInterface は,ネットワークコントローラから物理的なネットワークインターフェースの設定を取得します.

Get-NetworkControllerServiceInsertion は,ネットワークコントローラからサービス挿入リソースの属性を取得します.

Get-NetworkControllerState は,ネットワークコントローラーステートリソースのプロビジョニング状態を回収します.

[Get-NetworkControllerStatistics] (Get-NetworkControllerStatistics.md) は,ネットワークコントローラ内のリソースの健康と利用統計を表示します.

Get-NetworkControllerSubnetEgressReset は,ネットワークコントローラのためのサブネット出力リセットオブジェクトを取得します.

Get-NetworkControllerVirtualGateway は,仮想ゲートウェイの1つまたは複数の設定を取得します.

# NetworkController Module

## Description
This reference provides cmdlet descriptions and syntax for all Network Controller cmdlets.

## NetworkController Cmdlets

### [Add-NetworkControllerNode](./Add-NetworkControllerNode.md)
Adds a network controller node to an existing network controller deployment.

### [Clear-NetworkControllerNodeContent](./Clear-NetworkControllerNodeContent.md)
Clears Network Controller settings from a Network Controller node.

### [Disable-NetworkControllerNode](./Disable-NetworkControllerNode.md)
Disables a network controller node for maintenance purposes.

### [Enable-NetworkControllerNode](./Enable-NetworkControllerNode.md)
Enables a network controller node.

### [Get-NetworkController](./Get-NetworkController.md)
Gets network controller application settings.

### [Get-NetworkControllerAccessControlList](./Get-NetworkControllerAccessControlList.md)
Gets the access control list for a network controller.

### [Get-NetworkControllerAccessControlListRule](Get-NetworkControllerAccessControlListRule.md)
Gets a rule from an access control list for a network controller.

### [Get-NetworkControllerAuditingSettingsConfiguration](Get-NetworkControllerAuditingSettingsConfiguration.md)
Gets the firewall auditing settings for a Network Controller.

### [Get-NetworkControllerBackup](Get-NetworkControllerBackup.md)
Gets the status of a backup operation.

### [Get-NetworkControllerCluster](Get-NetworkControllerCluster.md)
Gets the network controller cluster settings.

### [Get-NetworkControllerConnectivityCheck](./Get-NetworkControllerConnectivityCheck.md)
Gets the Network Controller connectivity check.

### [Get-NetworkControllerConnectivityCheckResult](./Get-NetworkControllerConnectivityCheckResult.md)
Gets the Network Controller connectivity check result.

### [Get-NetworkControllerCredential](./Get-NetworkControllerCredential.md)
Retrieves a specified device credential or all device credentials from Network Controller.

### [Get-NetworkControllerDiagnostic](./Get-NetworkControllerDiagnostic.md)
Gets network controller diagnostic settings.

### [Get-NetworkControllerDiscovery](Get-NetworkControllerDiscovery.md)
Gets the network controller version and the versions of URIs supported by the controller.

### [Get-NetworkControllerFabricRoute](Get-NetworkControllerFabricRoute.md)
Gets the routes specified for logical subnet children of the logical network objects.

### [Get-NetworkControllerGateway](./Get-NetworkControllerGateway.md)
Gets the configuration of one or more gateway virtual machines.

### [Get-NetworkControllerGatewayPool](./Get-NetworkControllerGatewayPool.md)
Gets the configuration of one or more gateway pools.

### [Get-NetworkControllerIDnsServerConfiguration](Get-NetworkControllerIDnsServerConfiguration.md)
Gets a configuration object for an iDNS server for a Network Controller.

### [Get-NetworkControllerInternalResourceInstances](Get-NetworkControllerInternalResourceInstances.md)
Returns the mapping for instances IDs to REST resource IDs.

### [Get-NetworkControllerIpPool](Get-NetworkControllerIpPool.md)
