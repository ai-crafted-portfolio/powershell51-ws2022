Get-NetworkControllerNode ネットワーク制御器

SYNOPSISはネットワークコントローラーノード設定を入手します.

SYNTAX

Get-NetworkControllerNode [-Name <String>] [-ComputerName <String>] [-UseSsl] [-Credential <PSCredential>]
 [-CertificateThumbprint <String>] [<CommonParameters>]

記述 Get-NetworkControllerNode cmdlet は,ノード名,完全資格ドメイン名 (FQDN),IPアドレス,エラードメイン,ノードの代表的なステート転送 (REST) インターフェース,および,適用の場合,ノード証明書などのネットワークコントローラノード設定を取得します.

例えは,

例1: 展開中のネットワークコントローラノードをすべて取得する```

PS C:> Get-NetworkControllerNode Name : Node1 Server : NCNode1.contoso.com FaultDomain : fd:/host1/node1 RestInterface : Ethernet NodeCertificate : Status : Up Name : Node2 Server : NCNode2.contoso.com FaultDomain : fd:/host2/node2 RestInterface : Ethernet NodeCertificate : Status : Up Name : Node3 Server : NCNode3.contoso.com FaultDomain : fd:/host3/node3 RestInterface : Ethernet NodeCertificate : Status : Up


このコマンドは,ネットワークコントローラーノード設定を展開中のすべてのノードに設定します.

### 例2: ネットワークコントローラーノード設定を指定されたノードに名前で設定する```
PS C:\> Get-NetworkControllerNode -Name "Node1"
Node1Name       : Node1
Server          : NCNode1.contoso.com
FaultDomain     : fd:/host1/node1
RestInterface   : Ethernet
NodeCertificate : 
Status          : Up

このコマンドは,Node1という特定のノードのためのネットワークコントローラノード設定を入手します.

# Get-NetworkControllerNode

## SYNOPSIS
Gets the network controller node settings.

## SYNTAX

```
Get-NetworkControllerNode [-Name <String>] [-ComputerName <String>] [-UseSsl] [-Credential <PSCredential>]
 [-CertificateThumbprint <String>] [<CommonParameters>]
```

## DESCRIPTION
The **Get-NetworkControllerNode** cmdlet gets the network controller node settings such as the node name, fully qualified domain name (FQDN), IP address, fault domain, representational state transfer (REST) interface of the node, and the node certificate, if applicable.

## EXAMPLES

### Example 1: Get all network controller nodes in a deployment
```
PS C:\> Get-NetworkControllerNode
Name            : Node1
Server          : NCNode1.contoso.com
FaultDomain     : fd:/host1/node1
RestInterface   : Ethernet
NodeCertificate : 
Status          : Up
Name            : Node2
Server          : NCNode2.contoso.com
FaultDomain     : fd:/host2/node2
RestInterface   : Ethernet
NodeCertificate : 
Status          : Up
Name            : Node3
Server          : NCNode3.contoso.com
FaultDomain     : fd:/host3/node3
RestInterface   : Ethernet
NodeCertificate : 
Status          : Up
```

This command gets the network controller node settings for all nodes in the deployment.

### Example 2: Get network controller node settings for a specified node by name
```
PS C:\> Get-NetworkControllerNode -Name "Node1"
Node1Name       : Node1
Server          : NCNode1.contoso.com
FaultDomain     : fd:/host1/node1
RestInterface   : Ethernet
NodeCertificate : 
Status          : Up
```

This command gets the network controller node settings for a specific node named Node1.
