Microsoft.WSMan.Management Module を使用する

記述 記述

このセクションには,PowerShell Microsoft.WSMan.Management モジュールでインストールされているcmdletのサポートトピックが含まれています.WSMan モジュールには,PowerShellでWS-Management プロトコルを管理するcmdletとプロバイダーが含まれています.

Microsoft.WSMan.Management Cmdlets について

Connect-WSMan リモートコンピュータでWinRMサービスに接続します.

Disable-WSManCredSSP はコンピュータで CredSSP認証を無効にする.

[Disconnect-WSMan] (Discconnect-WSMan.md) リモートコンピュータのWinRMサービスからクライアントを離します.

Enable-WSManCredSSP コンピュータで CredSSP認証を有効にする.

Get-WSManCredSSP はクライアントのクレジットシールセキュリティサポートプロバイダー関連設定を取得します.

Get-WSManInstance は,リソースURIで指定されたリソースインスタンスの管理情報を表示します.

[Invoke-WSManAction] (Invoke-WSManAction.md) は,リソースURIと選択機によって指定されたオブジェクトに対するアクションを呼び出す.

[New-WSManInstance] (New-WSManInstance.md) は管理リソースの新しいインスタンスを作成します.

New-WSManSessionOption は,WS-Management cmdlets の入力パラメータとして使用するセッションオプションハッシュテーブルを作成します.

[Remove-WSManInstance] (Remove-WSManInstance.md) は管理リソースインスタンスを削除します.

Set-WSManInstance は,リソースに関連した管理情報を修正します.

Set-WSManQuickConfig は,ローカルコンピュータをリモート管理のために構成します.

[Test-WSMan] (テスト-WSMan.md) テストは, WinRM サービスがローカルコンピュータまたはリモートコンピュータで実行されているかどうかをテストします.

# Microsoft.WSMan.Management Module

## Description

This section contains the help topics for the cmdlets that are installed with PowerShell
Microsoft.WSMan.Management module. The WSMan module contains cmdlets and providers that manage the
WS-Management protocol in PowerShell.

## Microsoft.WSMan.Management Cmdlets

### [Connect-WSMan](Connect-WSMan.md)
Connects to the WinRM service on a remote computer.

### [Disable-WSManCredSSP](Disable-WSManCredSSP.md)
Disables CredSSP authentication on a computer.

### [Disconnect-WSMan](Disconnect-WSMan.md)
Disconnects the client from the WinRM service on a remote computer.

### [Enable-WSManCredSSP](Enable-WSManCredSSP.md)
Enables CredSSP authentication on a computer.

### [Get-WSManCredSSP](Get-WSManCredSSP.md)
Gets the Credential Security Support Provider-related configuration for the client.

### [Get-WSManInstance](Get-WSManInstance.md)
Displays management information for a resource instance specified by a Resource URI.

### [Invoke-WSManAction](Invoke-WSManAction.md)
Invokes an action on the object that is specified by the Resource URI and by the selectors.

### [New-WSManInstance](New-WSManInstance.md)
Creates a new instance of a management resource.

### [New-WSManSessionOption](New-WSManSessionOption.md)
Creates session option hash table to use as input parameters for WS-Management cmdlets.

### [Remove-WSManInstance](Remove-WSManInstance.md)
Deletes a management resource instance.

### [Set-WSManInstance](Set-WSManInstance.md)
Modifies the management information that is related to a resource.

### [Set-WSManQuickConfig](Set-WSManQuickConfig.md)
Configures the local computer for remote management.

### [Test-WSMan](Test-WSMan.md)
Tests whether the WinRM service is running on a local or remote computer.
