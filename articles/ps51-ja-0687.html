DFSR モジュール

この参照は,すべての分散ファイルシステム (DFS) 複製 cmdlet の cmdlet の説明と構文を提供します.この参照は, cmdlet の初めの動詞に基づいて,アルファベティ順で cmdlet をリストします.

DFSR Cmdlets について

Add-DfsrConnection は,複製グループのメンバー間で接続を作成します.

Add-DfsrMember は,複製グループにコンピュータを追加します.

ConvertFrom-DfsrGuid は,特定の複製グループ内の友好な名前にGUIDを翻訳します.

Export-DfsrClone クローンされたDFSレプリカーションデータベースとボリューム設定を輸出します.

Get-DfsrBacklog は,DFS複製パートナー2人の間に待機中のファイル更新のリストを回収します.

Get-DfsrCloneState はデータベースのクローン操作のステータスを取得します.

Get-DfsrConnection は,DFS 複製パートナーとの接続を取得します.

Get-DfsrConnectionSchedule は,複製グループのメンバー間の接続スケジュールを取得します.

Get-DfsrDelegation は,複製グループに権限があるプリンセルを取得します.

Get-DfsReplicatedFolder は,複製グループから複製されたフォルダを取得します.

Get-DfsReplicationGroup は複製グループを回収する.

Get-DfsrFileHash はファイルハッシュを取得します.

Get-DfsrGroupSchedule は,複製グループスケジュールを回収します.

Get-DfsrIdRecord は,DFS Replication データベースから複製されたファイルまたはフォルダのID記録を取得します.

Get-DfsrMember は,複製グループ内のメンバーコンピュータを入手します.

Get-DfsrMembership 複製グループのメンバーのための会員制設定を取得します.

Get-DfsrPreservedFiles は,DFS Replication が以前に保存したファイルとフォルダのリストを取得します.

Get-DfsrServiceConfiguration はグループメンバーのDFS複製サービス設定を入手します.

Get-DfsrState は,メンバーのDFS複製状態を取得します.

Grant-DfsrDelegation 複製グループのためのセキュリティ・プリンセントに権限を許可する.

Import-DfsrClone クローンされたDFSレプリカーションデータベースとボリューム設定を輸入します.

New-DfsReplicatedFolder は,複製グループで複製されたフォルダを作成します.

New-DfsReplicationGroup は複製グループを作成します.

Remove-DfsrConnection 複製グループのメンバー間の接続を削除します.

Remove-DfsReplicatedFolder 複製グループから複製されたフォルダを削除します.

[DfsReplicationGroup.md] (※/DfsReplicationGroup.md) 複製グループを削除する.

Remove-DfsrMember 複製グループからコンピュータを削除します.

DfsrPropagationTestFile DFS Replicationの拡散テストファイルを削除します.

Reset-DfsrCloneState クローン操作をキャンセルします.

Restore-DfsrPreservedFiles は,DFS Replication が以前に保存したファイルとフォルダを復元します.

Revoke-DfsrDelegation 複製グループに対するセキュリティ・プリンセルの権限を撤回します.

Set-DfsrConnection 複製グループのメンバー間の接続の設定を変更します.

Set-DfsrConnectionSchedule 複製グループのメンバー間の接続スケジュールの設定を変更します.

Set-DfsReplicatedFolder 複製されたフォルダの設定を変更します.

Set-DfsReplicationGroup は複製グループを修正する.

Set-DfsrGroupSchedule は,複製グループスケジュールを変更します.

Set-DfsrMember は,複製グループ内のメンバーコンピュータ情報を修正します.

Set-DfsrMembership 複製グループメンバーの会員制設定を設定します.

Set-DfsrServiceConfiguration は,DFS複製サービスのための設定を変更します.

Start-DfsrPropagationTest は,複製されたフォルダでプロパガンダテストファイルを作成します.

Suspend-DfsReplicationGroup スケジュールに関係なくコンピュータ間の複製を停止します.

Sync-DfsReplicationGroup はスケジュールに関係なくコンピュータ間の複製を同期します.

DFSrConfigurationFromAD は,DFS Replication サービスの更新を開始します.

DFSRHealthReport は,DFSレプリケーションの健康報告を生成します.

Write-DfsrPropagationReport 複製グループでのプロパガンダテストファイルに関するレポートを生成します.

# DFSR Module

## Description
This reference provides cmdlet descriptions and syntax for all Distributed File System (DFS) Replication cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

## DFSR Cmdlets

### [Add-DfsrConnection](./Add-DfsrConnection.md)

### [Add-DfsrMember](./Add-DfsrMember.md)
