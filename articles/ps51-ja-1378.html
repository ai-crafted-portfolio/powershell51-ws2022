テスト-VipReachability

シノプシスは,DIPSが達成可能なかどうかをテストします.

SYNTAX

Test-VipReachability [[-OperationId] <String>] [-SourceIP] <String> [[-CompartmentId] <String>]
 [-TargetVIP] <String> [-Muxes] <Hashtable[]> [-Dips] <Hashtable[]> [[-SequenceNumber] <Int32>]
 [[-PayloadSize] <Int32>] [<CommonParameters>]

記述 テスト-VipReachability* cmdletは,指定されたマルチプレッサー (MUX) を介してデータセンターIPアドレス (DIP) のリストにアクセスできるか否かをテストします.

テストでは,Muxノードへの3層接続,そしてMuxノードからDIPホストへの接続を対象としています.

テストはまず,インターネット制御メッセージプロトコル (ICMP) のエコー要求を仮想IP (VIP) アドレスに送信します. MUXはエコー要求を傍受し,対象のVIPから来るように見える応答を送信します.

その後,テストは,MUXホストからプロバイダーネットワーク上のDIPホストにICMPエコーリクエストを送信します.テストの結果は,輸出オブジェクトで報告されます.

&lt;Int32&gt;] [[-PayloadSize] &lt;Int32&gt;] [&lt;CommonParameters&gt;] ``` ## DESCRIPTION The **Test-VipReachability** cmdlet tests whether a list of datacenter IP addresses (DIPs) can be reached through the specified multiplexers (MUXes). The test covers layer-3 connectivity to the MUX nodes, and from the MUX nodes to the DIP hosts. The test first sends Internet Control Message Protocol (ICMP) echo requests to the virtual IP (VIP) address. The MUX intercepts the echo requests and sends responses that appear to come from the targeted VIP. The test then sends ICMP echo requests from the MUX host to the DIP host on the provider network. The results of the test are reported in the output object. ## EXAMPLES ### Example 1: Test VIP reachability ``` PS C:\&gt; for ($mux in $VipHostMapping.MuxList) { $secpasswd = ConvertTo-SecureString &lt;plaintext password&gt; -AsPlainText -Force $creds = New-Object System.Management.Automation.PSCredential (&lt;username&gt;, $secpasswd) $mux.Credentials = $creds } PS C:\&gt; for ($dip in $VipHostMapping.DIPHosts) { $secpasswd = ConvertTo-SecureString &lt;plaintext password&gt; -AsPlainText -Force $creds = New-Object System.Management.Automation.PSCredential (&lt;username&gt;, $secpasswd) $dip.HostInfo.Credentials = $creds } PS C:\&gt; Test-VIPReachability -OperationId 1 -SourceIP &quot;10.123.176.108&quot; -TargetVIP &quot;10.123.177.110&quot; -Muxes $VipHostMapping.MuxList -Dips $VipHostMapping.DIPHosts ``` The first command populates the credentials for the MUX nodes to test.
