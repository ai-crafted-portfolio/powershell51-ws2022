IscsiTarget モジュールは

この参照は,すべての iSCSI ターゲットサービス特定のcmdletのcmdletのCMdlet説明と構文を提供します.この参照は,cmdletの開始にある動詞に基づいてアルファベット順でcmdletをリストします.

IscsiTarget Cmdlets は,Cmdlets を使用する

Add-IscsiVirtualDiskTargetMapping 仮想ディスクを iSCSIターゲットに割り当てます.

Checkpoint-IscsiVirtualDisk は仮想ディスクのスナップショットを作成します.

Convert-IscsiVirtualDisk は,iSCSI仮想ディスクを4Kセクターに並べられた高度な仮想ディスク 1.0フォーマットに変換します.

Dismount-IscsiVirtualDiskSnapshot 瞬間の縮小を図っています.

Export-IscsiTargetServerConfiguration は iSCSI ターゲットサーバーの構成を輸出しています.

Export-IscsiVirtualDiskSnapshot は,iSCSI仮想ディスクスnapshotを輸出する.

[Get-IscsiServerTarget] (/Get-IscsiServerTarget.md) は, iSCSI ターゲットとその関連性を取得します.

Get-IscsiTargetServerSetting は,iSCSIターゲット,仮想ディスク,またはスナップショットのグローバル設定または一般的な設定を取得します.

Get-IscsiVirtualDisk は,iSCSI仮想ディスクとその関連性を持つものを入手します.

Get-IscsiVirtualDiskSnapshot は,スナップショットの性質を得ます.

Import-IscsiTargetServerConfiguration は iSCSI ターゲットサーバーの構成を輸入する.

Import-IscsiVirtualDisk は,既存の仮想ハードディスク (VHD) ファイルを使用して, iSCSI Virtual Disk オブジェクトを追加します.

Mount-IscsiVirtualDiskSnapshot は,本地でスナップショットをマウントします.

New-IscsiServerTarget は指定された名前を持つ新しい iSCSI Target オブジェクトを作成します.

New-IscsiVirtualDisk は,指定したファイルパスとサイズを持つ iSCSI仮想ディスクを作成します.

[Remove-IscsiServerTarget] ([[Remove-IscsiServerTarget.md]/Remove-IscsiServerTarget.md) は指定された iSCSI ターゲットを削除します.

Remove-IscsiVirtualDisk 仮想ハードディスク (VHD) ファイルを削除せずに,仮想ディスクオブジェクトを削除します.

Remove-IscsiVirtualDiskSnapshot は指定されたスナップショットを削除します.

Remove-IscsiVirtualDiskTargetMapping 指定された iSCSI仮想ディスクと指定された iSCSIターゲットとの間の割り当てを削除します.

Resize-IscsiVirtualDisk は,iSCSI仮想ディスクをサイズ変更しています.

Restore-IscsiVirtualDisk 瞬時に仮想ディスクを復元する.

Set-IscsiServerTarget は指定された iSCSI ターゲットの設定を変更します.

Set-IscsiTargetServerSetting は,iSCSIターゲット仮想ディスクのグローバル設定または一般的な設定を設定します.

Set-IscsiVirtualDisk は指定された iSCSI仮想ディスクの設定を変更します.

Set-IscsiVirtualDiskSnapshot 瞬間の説明を設定する.

[Stop-IscsiVirtualDiskOperation] (Stop-IscsiVirtualDiskOperation.md) は,iSCSI仮想ディスク上で進行中の長期間実行中の操作を停止します.

# IscsiTarget Module

## Description
This reference provides cmdlet descriptions and syntax for all iSCSI target service-specific cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

### [Dismount-IscsiVirtualDiskSnapshot](./Dismount-IscsiVirtualDiskSnapshot.md)
