# Set-ClusterFaultDomainXML

## SYNOPSIS
Sets the cluster fault domain using XML.

## SYNTAX

```
Set-ClusterFaultDomainXML [-XML] <String> [-Flags <UInt32>] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## DESCRIPTION
