# Set-DhcpServerv4FilterList

## SYNOPSIS
Sets the enabled state for the allow and the deny MAC address filter lists on the DHCP server service.

## SYNTAX

```
Set-DhcpServerv4FilterList [-ComputerName <String>] [[-Allow] <Boolean>] [[-Deny] <Boolean>] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Set-DhcpServerv4FilterList** cmdlet sets the enabled state for the allow and the deny MAC address filter lists on the Dynamic Host Configuration Protocol (DHCP) server service.

## EXAMPLES

### Example 1: Enable filter lists on the DHCP server service
```
PS C:\> Set-DhcpServerv4FilterList -ComputerName "dhcpserver.contoso.com" -Allow $True -Deny $True
```

This example enables the allow filter and the deny filter lists on the DHCP server service that runs on the computer named dhcpserver.contoso.com.
