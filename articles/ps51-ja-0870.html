Expand-WindowsCustomDataImage はカスタムデータ画像を拡張する.

Get-AppxProvisionedPackage は,新しいユーザーごとにインストールされる画像で,アプリパッケージ (.appx) の情報を入手します.

Get-NonRemovableAppsPolicy は,非移除可能なアプリとしてインストールされ,設定されているアプリパッケージのリストを返します.

Get-WIMBootEntry は,指定されたディスク容量に関する Windows 画像ファイルブート (WIMBoot) 構成エントリを表示します.

Get-WindowsCapability は,画像や実行中のオペレーティングシステムに Windows の機能を備えている.

Get-WindowsDriver は,Windows画像でドライバーに関する情報を表示します.

Get-WindowsEdition は,Windows画像に関する編集情報を取得します.

Get-WindowsImage は,WIMまたはVHDファイルでWindows画像に関する情報を入手します.

Get-WindowsImageContent は指定された画像のファイルやフォルダのリストを表示します.

Get-WindowsOptionalFeature は,Windows画像でオプションの機能に関する情報を入手します.

Get-WindowsPackage は,Windows画像でパッケージに関する情報を入手します.

Get-WindowsReservedStorageState は画像の予約されたストレージ状態を表示します.

Mount-WindowsImage は,WIMまたはVHDファイルでWindows画像をローカルコンピュータのディレクトリにマウントします.

New-WindowsCustomImage は,Windows Image File Boot (WIMBoot) を構成したデバイスでカスタマイズされたまたはサービスされたWindowsコンポーネントの画像をキャプチャします.

New-WindowsImage は,ドライブの画像を新しいWIMファイルに収録します.

Optimize-AppXProvisionedPackages は,同じファイルにハードリンクを入れ替えて,画像上のプロビジョニングされたパッケージの総ファイルサイズを最適化します.

Optimize-WindowsImage は,指定された最適化でWindows画像を構成します.

Remove-AppxProvisionedPackage Windows 画像からアプリパッケージ (.appx) を削除する.

Remove-WindowsCapability 画像からWindows機能パッケージをアンインストールします.

Remove-WindowsDriver は,オフラインのWindows画像からドライバーを削除します.

Remove-WindowsImage は,複数のボリューム画像を持つWIMファイルから指定されたボリューム画像を削除します.

Remove-WindowsPackage は,Windows画像からパッケージを削除します.

Repair-WindowsImage ワイムまたはVHDファイルでWindows画像を修復する.

Save-WindowsImage は,マウントされた画像に変更を加え,WIMまたはVHDファイルに適用します.

Set-AppXProvisionedDataFile は,Windows画像で配置された指定されたアプリ (.appx) パッケージにカスタムデータを追加します.

Set-NonRemovableAppsPolicy アプリパッケージを非移除可能 (アンインストールできない) と設定する.

WindowsEdition Windowsの画像をより高いバージョンに変更します.

Set-WindowsProductKey 画面のプロダクトキーを設定する.

Set-WindowsReservedStorageState 画像の予約されたストレージ状態を設定します.

Split-WindowsImage は既存の .wim ファイルを複数の読み込みのみの分割 .wim ファイルに分割します.

# DISM Module

## Description

The Deployment Image Servicing and Management (DISM) platform is used to mount and service Windows
images before deployment. A subset of DISM commands can be used on online Windows images. You can
use DISM tools to mount, and get information about, Windows image (`.wim`) files or virtual hard
disks (`.vhd` or `.vhdx`). You can also use it to install, uninstall, configure, and update Windows
features, packages, and drivers in a Windows image or to change the edition of a Windows image.

The DISM platform also includes a command-line tool, DISM.exe, and the
[DISM API](https://go.microsoft.com/fwlink/?LinkID=237611). The command-line tool is available in
the
[Windows Assessment and Deployment Kit (Windows ADK)](https://go.microsoft.com/fwlink/?LinkId=206587)
and includes additional functionality that supports servicing commands for international settings.

You can check for errors when running DISM cmdlets by checking if the `$?`. If set to True the last
operation succeeded. If False the last operation failed. The `$LASTEXITCODE` contains the exit code
of the last Win32 executable run. For example, to check that the `Get-WindowsImage` cmdlet fails to
get information about the Windows image contained in the file, `E:\images\c.wim`, type the
following:

```powershell
try
{

    Get-WindowsImage -ImagePath E:\images\c.wim
}
catch
{
    $message = "TRAPPED: {0}: '{1}'" -f ($_.Exception.GetType().FullName), ($_.Exception.Message)
    Write-host $message
}

```

For more information about error handling, see the
[about_Try_Catch_Finally](https://go.microsoft.com/fwlink/p/?LinkID=317390).
