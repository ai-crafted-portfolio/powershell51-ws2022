# BCDowngradingを有効にします.

## SYNOPSISは,ダウングレードモードでオペレーティングシステムを実行しているクライアントコンピュータに指示します.

## SYNTAXは,のシンタックスです.

```
Enable-BCDowngrading [[-Version] <PreferredContentInformationVersion>] [-Force] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## 記述 **Enable-BCDowngrading** cmdlet は,Windowsオペレーティングシステムの後バージョンを実行しているクライアントコンピュータにDowngraded モードで動作するよう指示します.このモードでは,クライアントはコンテンツサーバーに以前のバージョンのバージョンの要求を送信し,コンテンツサーバーはコンテンツ情報の以前のバージョンをクライアントに送信して応答します.

注:Windows(R)7ベースのBranchCacheクライアントコンピュータは,この設定の影響を受けていません.

## 例えは

### 例1: 降格モードで操作する```
PS C:\> Enable-BCDowngrading
```

このコマンドはクライアントコンピュータにダウングレードモードで動作するように指示します.

###英語原文###
# Enable-BCDowngrading

## SYNOPSIS
Instructs a client computer that is running an operating system in a downgraded mode.

## SYNTAX

```
Enable-BCDowngrading [[-Version] <PreferredContentInformationVersion>] [-Force] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Enable-BCDowngrading** cmdlet instructs a client computer that is running a later version of the Windows operating system to operate in a downgraded mode.
In this mode, the client sends previous version-specific version requests to content servers, and content servers respond by sending previous versions of content information to the client.

Note: Windows(R) 7-based BranchCache client computers are not affected by this setting.

## EXAMPLES

### Example 1: Operate in downgraded mode
```
PS C:\> Enable-BCDowngrading
```

This command instructs a client computer to operate in a downgraded mode.
