# Remove-VirtualDiskFromMaskingSet を削除する

## SYNOPSISは,マスクセットで定義された InitiatorIds オブジェクトによる仮想ディスクへのアクセスをブロックするために,指定されたマスクセットから仮想ディスクを削除します.

## SYNTAXは,のシンタックスです.

### ByFriendlyName (デフォルト) ```
Remove-VirtualDiskFromMaskingSet [-MaskingSetFriendlyName] <String[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

### ByUniqueId ```
Remove-VirtualDiskFromMaskingSet -MaskingSetUniqueId <String[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

### InputObject (cdxml) を入力する```
Remove-VirtualDiskFromMaskingSet -InputObject <CimInstance[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## 記述 削除-仮想ディスクFromMaskingSet** cmdlet は,指定されたマスクセットから仮想ディスクを削除し,マスクセットで定義されたイニシアターアイドオブジェクトによって仮想ディスクへのアクセスをブロックします.

ps_storage_spacesubsystem_not_remark

## 例えは

### 例1 ```
PS C:\>Remove-VirtualDiskFromMaskingSet -MaskingSetFriendlyName "Masking Set 1" -VirtualDiskNames "Virtual Disk 1,Virtual Disk 2,Virtual Disk 3"
```

この例では,マスクセットから仮想ディスクを削除します.

###英語原文###
# Remove-VirtualDiskFromMaskingSet

## SYNOPSIS
Removes a virtual disk from a specified masking set to block access to the virtual disk by an InitiatorIds object defined in the masking set.

## SYNTAX

### ByFriendlyName (Default)
```
Remove-VirtualDiskFromMaskingSet [-MaskingSetFriendlyName] <String[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

### ByUniqueId
```
Remove-VirtualDiskFromMaskingSet -MaskingSetUniqueId <String[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

### InputObject (cdxml)
```
Remove-VirtualDiskFromMaskingSet -InputObject <CimInstance[]> [-VirtualDiskNames <String[]>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
The **Remove-VirtualDiskFromMaskingSet** cmdlet removes a virtual disk from a specified masking set to block access to the virtual disk by an InitiatorIds object defined in the masking set.

ps_storage_spacesubsystem_not_remark

## EXAMPLES

### EXAMPLE 1
```
PS C:\>Remove-VirtualDiskFromMaskingSet -MaskingSetFriendlyName "Masking Set 1" -VirtualDiskNames "Virtual Disk 1,Virtual Disk 2,Virtual Disk 3"
```

This example removes a virtual disk from a masking set.
