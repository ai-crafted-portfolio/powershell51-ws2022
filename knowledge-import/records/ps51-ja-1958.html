# ネットワークアダプターRscを有効にします.

## SYNOPSISはネットワークアダプターで RSC を有効にします.

## SYNTAXは,のシンタックスです.

### ByName (デフォルト) ```
Enable-NetAdapterRsc [-Name] <String[]> [-IncludeHidden] [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### ByInstanceID ```
Enable-NetAdapterRsc -InterfaceDescription <String[]> [-IncludeHidden] [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject (cdxml) を入力する```
Enable-NetAdapterRsc -InputObject <CimInstance[]> [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## 記述: *Enable-NetAdapterRsc** cmdletはネットワークアダプターでセグメントコアレス (RSC) を受信できるようにします.IPv4またはIPv6が指定されている場合,どちらも有効です.RSCは同じ中断期間に受信された複数のパケットを取り込み,パケットを単一の大きなパケットに組み合わせ,ネットワークスタックで処理されます. これにより,入ってくるパケットの処理オーバーヘッドを削減し,使用されるプロセッササイクル数を削減し,より優れたスケーラビリティにつながります.

## 例えは

### 例1:指定されたネットワークアダプターで IPv4 の RSC を有効にします.```
PS C:\> Enable-NetAdapterRsc -Name "MyAdapter" -IPv4
```

このコマンドは,MyAdapterというネットワークアダプタで IPv4のRSCを有効にして,ネットワークアダプタを再起動します.

### 例2:指定されたネットワークアダプターで IPv4 および IPv6 の RSC を有効にします.```
PS C:\> Enable-NetAdapterRsc -Name "MyAdapter"
```

このコマンドはMyAdapterというネットワークアダプターで IPv4と IPv6の両方のRSCを有効にし,ネットワークアダプターを再起動します.

### 例3:すべてのネットワークアダプターでIPv4とIPv6のRSCを有効にします.```
PS C:\> Enable-NetAdapterRsc -Name "*"
```

この例では,RSCが IPv4と IPv6およびすべてのRSC対応ネットワークアダプタを有効にし,ネットワークアダプタを再起動できます.

# Enable-NetAdapterRsc

## SYNOPSIS
Enables RSC on a network adapter.

## SYNTAX

### ByName (Default)
```
Enable-NetAdapterRsc [-Name] <String[]> [-IncludeHidden] [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### ByInstanceID
```
Enable-NetAdapterRsc -InterfaceDescription <String[]> [-IncludeHidden] [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject (cdxml)
```
Enable-NetAdapterRsc -InputObject <CimInstance[]> [-IPv4] [-IPv6] [-NoRestart] [-PassThru]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Enable-NetAdapterRsc** cmdlet enables receive segment coalescing (RSC) on a network adapter.
If the IPv4 or IPv6 is specified, then both are enabled.
RSC takes multiple packets received within the same interrupt period and combines the packets into a single large package to be processed by the network stack.
This reduces the processing overhead for incoming packets and reduces the number of processor cycles that are used, leading to better scalability.

## EXAMPLES

### Example 1: Enable RSC for IPv4 on the specified network adapter
```
PS C:\> Enable-NetAdapterRsc -Name "MyAdapter" -IPv4
```

This command enables RSC for IPv4 on the network adapter named MyAdapter and restarts the network adapter.

### Example 2: Enable RSC for IPv4 and IPv6 on the specified network adapter
```
PS C:\> Enable-NetAdapterRsc -Name "MyAdapter"
```

This command enables RSC for both IPv4 and IPv6 on the network adapter named MyAdapter and restarts the network adapter.

### Example 3: Enable RSC for IPv4 and IPv6 on all network adapters
```
PS C:\> Enable-NetAdapterRsc -Name "*"
```

This example enables RSC for IPv4 and IPv6 and all RSC capable network adapters and restarts the network adapters.
