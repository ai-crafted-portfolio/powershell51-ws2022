# ストップ・トラス

## SYNOPSIS 事件追跡ログインセッションを停止します.

## SYNTAX 

```
Stop-Trace [-SessionName] <Object> [-ETS] [<CommonParameters>]
```

## 記述は,

このcmdletはWindowsイベントトラスログセッションを停止します.

このcmdletは以下のcmdletsによって使用されます:

 - -`Disable-PSWSManCombinedTrace` - -`Disable-WSManTrace`

このcmdletは,高度なPowerShellセッションから実行する必要があります.

## 例えは,

### 例1:WSMan Trace ログインセッションを停止する

```powershell
Stop-Trace -SessionName 'wsmlog'
```

# Stop-Trace

## SYNOPSIS
Stop an Event Trace logging session.

## SYNTAX

```
Stop-Trace [-SessionName] <Object> [-ETS] [<CommonParameters>]
```

## DESCRIPTION

This cmdlet stops a Windows Event Trace logging session.

This cmdlet is used by the following cmdlets:

- `Disable-PSWSManCombinedTrace`
- `Disable-WSManTrace`

You must run this cmdlet from an elevated PowerShell session.

## EXAMPLES

### Example 1: Stop a WSMan Trace logging session

```powershell
Stop-Trace -SessionName 'wsmlog'
```
