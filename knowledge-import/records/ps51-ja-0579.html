## 記述は,

   `Set-CauClusterRole`cmdlet は指定されたクラスター上のクラスター認識更新 (CAU) クラスタード役割のための構成属性を設定します.この cmdlet では,更新日程や更新実行パラメータなどの属性が指定できます.

このcmdletを **PostUpdateScript**または **PreUpdateScript** パラメータで実行するには,各ノードでWindows PowerShell リモート処理が有効である必要があります.`Enable-PSRemoting`cmdlet.さらに,各ノードでWindows リモート管理 - 互換性モード (HTTP-In) ファイアウォール例外が有効であることを確認してください.

## 例えは

### 例1: 設定設定設定を設定する CAU クラスターの役割は,指定されたクラスターの月の最初の週と2週間の

```powershell
$parameters = @{
    ClusterName = 'CONTOSO-FC1'
    DaysOfWeek = 'Tuesday'
    WeeksOfMonth = '1,2'
    RebootTimeoutMinutes = '10'
    Force = $true
}
Set-CauClusterRole $parameters
```

このコマンドは, **CONTOSO-FC1**というクラスタ上のCAUクラスタロールの設定を設定します.CAUクラスタロールは,毎月の1週2週目,火曜日に更新実行を行うように設定されています.CAUクラスタロールは,再起動が必要であれば,各ノードを再起動するのに10分を許可します.この時間内に再起動が完了しない場合は,そのノード上の更新実行が失敗としてマークされます.コマンドは**Force**パラメータを指定しているため,cmdletは確認提示が表示されないまま実行されます.

この例では,パラメータ値を から転送するためにスプラッティングを使用します.`$parameters`[Splatting] (/powershell/module/microsoft.powershell.core/about/about_splatting) に関する詳細をご覧ください.

### 例3:指定されたクラスターで更新実行を開始します

```powershell
Set-CauClusterRole -ClusterName "CONTOSO-FC1" -UpdateNow -Force
```

このコマンドは,CAUクラスタロールが**CONTOSO-FC1**というクラスタに即座に更新実行を開始するよう促します.このコマンドは**Force**パラメータを指定しているため,cmdletは確認提示が表示されないまま実行されます

### -CauPluginArguments

各更新プラグインで使用する name=value pairs の集合を,議論として指定します.

例えば,一つのプラグインのドメイン引数を指定するには:

 - -`@{Domain=Domain.local}`

半球で分離した集合で複数のペアを指定できます.例えば:

 - -`@{name1=value1;name2=value2;name3=value3}`

これらの name=value pairs は,あなたが指定した **CauPluginName** パラメータに意味のあるものとする必要があります.複数のプラグインの為の議論を指定した場合,コマで分離した **CauPluginName** の値を渡す順に,name=value pairs の集合を指定してください.例えば:

 - -`@{name1=value1;name2=value2;name3=value3},@{name4=value4;name5=value5}`

デフォルトのMicrosoft.WindowsUpdatePlugin のプラグインでは,議論は必要ありません.以下の議論はオプションです:

**'IncludeRecommendedUpdates'='\<Value\>'**:各ノードに重要な更新に加えて推奨された更新が適用されることを示唆するブール値.指定されていない場合,デフォルト値は偽である. - Windows Update Agentの標準的なクエリ文字列で,Windows Update Agentが各ノードに適用される更新をフィルタリングするために使用する基準を指定する.名前には**QueryString**を使用し,値としては,引用符で完全なクエリを付加する.指定されていない場合,デフォルトとして **Microsoft.WindowsUpdatePlugin**のプラグインは以下の議論を使用します. - `QueryString="IsInstalled=0 and Type='Software' and IsHidden=0 and IsAssigned=1"`

デフォルトのクエリ・ストリングについて詳しくは,クエリ・ストリングに含まれるIsInstalledなどの基準については, [IUpdateSearcher::Search method] (/windows/win32/api/wuapi/nf-wuapi-iupdatesearcher-search) を参照してください.

**Microsoft.HotfixPlugin**プラグインでは,次の議論が求められます.

- **HotfixRootFolderPath=\<Path\>**: SMBのホットフィックスルーツフォルダへのUNC経路は,適用される更新が含まれる構造とホットフィックス構成ファイルを含む構造と共有しています.

次の議論は,Microsoft.HotfixPlugin**プラグインのオプションです.

**RequireSmbEncryption=\<Value\>**:ブルース値は,SMB シェアからのデータへのアクセスのためにSMB 暗号化が強制されることを示します.指定されていない場合は,デフォルト値は偽です.SMB シェアからアクセスされたデータの完全性を確保するために,プラグインは,シェアがSMB サインまたはSMB 暗号化に有効であることを要求します. - **DisableAclChecks=\<Value\>**:ブルース値は,プラグインがホットルーツフォルダーとホットフィックス構成ファイルで十分な許可を確認することを示すものです.指定されていない場合は,デフォルト値は偽です. - **HotfixInstallerMinutes=<IntegerMinutes>\**: ホットフィックスインストーラーがプロを許可する時間長さ.ocess to return. 指定されていない場合は,デフォルト値は30分です. - **HotfixConfigFileName=\<name\>**: ホットフィックス構成ファイルの名前.指定されていない場合は,デフォルト名は `DefaultHotfixConfig.xml`**Microsoft.HotfixPlugin**プラグインの必要とオプションの議論については, [Cluster-Aware Updating plug-ins work] (/windows-server/failover-clustering/cluster-aware-updating-plug-ins) を参照してください.

## DESCRIPTION

The `Set-CauClusterRole` cmdlet sets configuration properties for the Cluster-Aware Updating (CAU)
clustered role on the specified cluster. This cmdlet can specify properties such as the updating
schedule and updating run parameters.

To run this cmdlet with the **PostUpdateScript** or **PreUpdateScript** parameters, Windows
PowerShell remoting must be enabled on each node. To do this, use the `Enable-PSRemoting` cmdlet.
In addition, ensure that the **Windows Remote Management - Compatibility Mode (HTTP-In)** firewall
exception is enabled on each node.

## EXAMPLES

### Example 1: Configure settings for a CAU cluster role on the specified cluster on the first and second weeks of the month

```powershell
$parameters = @{
    ClusterName = 'CONTOSO-FC1'
    DaysOfWeek = 'Tuesday'
    WeeksOfMonth = '1,2'
    RebootTimeoutMinutes = '10'
    Force = $true
}
Set-CauClusterRole $parameters
```

This command configures settings for the CAU clustered role on the cluster named **CONTOSO-FC1**. The
CAU clustered role is configured to perform updating runs on Tuesdays on the first and second weeks
of each month. The CAU clustered role allows 10 minutes for the restarting of each node, if a
restart is necessary. If the restart doesn't complete within this time, then the updating run on
that node is marked as failed. Because the command specifies the **Force** parameter, the cmdlet
runs without displaying confirmation prompts.

This example uses splatting to pass parameter values from the `$parameters` variable to the command.
Learn more about [Splatting](/powershell/module/microsoft.powershell.core/about/about_splatting).

- **DisableAclChecks=\<Value\>**: Boolean value to indicate that the plug-in will check for
