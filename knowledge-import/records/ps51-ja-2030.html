# Remove-NetEventProvider を削除する

## SYNOPSISは,セッションから ETW プロバイダーを削除します.

## SYNTAXは,のシンタックスです.

### 名前名 ```
Remove-NetEventProvider [-Name] <String[]> [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject (cdxml) を入力する```
Remove-NetEventProvider -InputObject <CimInstance[]> [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>]
 [-AsJob] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## 記述 削除ネットエベントプロバイダー* cmdlet は,セッションからイベント追跡 Windows (ETW) プロバイダを削除します.

## 例えは

### 例1: ETWプロバイダを削除する```
PS C:\>Remove-NetEventProvider -Name "Microsoft-Windows-TCPIP"

このコマンドは,Microsoft-Windows-TCPIPという名前のETWプロバイダを削除します.

# Remove-NetEventProvider

## SYNOPSIS
Removes an ETW provider from a session.

## SYNTAX

### ByName
```
Remove-NetEventProvider [-Name] <String[]> [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob]
 [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject (cdxml)
```
Remove-NetEventProvider -InputObject <CimInstance[]> [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>]
 [-AsJob] [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The **Remove-NetEventProvider** cmdlet removes an Event Tracing for Windows (ETW) provider from a session.

## EXAMPLES

### Example 1: Remove an ETW provider
```
PS C:\>Remove-NetEventProvider -Name "Microsoft-Windows-TCPIP"
```

This command removes an ETW provider named Microsoft-Windows-TCPIP.
