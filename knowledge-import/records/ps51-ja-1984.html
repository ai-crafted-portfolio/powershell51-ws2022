# NetAdapter Module について

## この参照の説明は,すべてのネットワークアダプター特定のcmdletのcmdletの説明と構文を提供します.この参照は,cmdletの初めの動詞に基づいてアルファベット順でcmdletをリストします.

## NetAdapter Cmdlets について

### [Disable-NetAdapter](./Disable-NetAdapter.md) ネットワークアダプターを無効にする.

### [Disable-NetAdapterBinding](./Disable-NetAdapterBinding.md) ネットワークアダプターへの結合を無効にする.

### [Disable-NetAdapterChecksumOffload](./Disable-NetAdapterChecksumOffload.md) ネットワークアダプターの選択されたチェックサムオフロードを無効にする.

### [Disable-NetAdapterEncapsulatedPacketTaskOffload](./Disable-NetAdapterEncapsulatedPacketTaskOffload.md) 封装されたパケットタスクオフロードを無効にする.

### [Disable-NetAdapterIPsecOffload](./Disable-NetAdapterIPsecOffload.md) は,ネットワークアダプターのIPsecオフロードを無効にし,ネットワークアダプターはパケットごとに暗号化操作を実行しないようにします.

### [Disable-NetAdapterLso](./Disable-NetAdapterLso.md) ネットワークアダプターのLSOv4とLSOv6などのすべてのLSOプロパティを無効にする.

### [Disable-NetAdapterPowerManagement] (Disable-NetAdapterPowerManagement.md) はネットワークアダプターの特定の電力管理機能を無効にします.

### [Disable-NetAdapterQos](./Disable-NetAdapterQos.md) ネットワークアダプターのQoSを無効にする.

### [Disable-NetAdapterRdma](./Disable-NetAdapterRdma.md) ネットワークアダプターで RDMAを無効にする.

### [Disable-NetAdapterRsc](./Disable-NetAdapterRsc.md) ネットワークアダプターでのRSCを無効にする.

### [Disable-NetAdapterRss](./Disable-NetAdapterRss.md) ネットワークアダプターで RSS を無効にする.

### [Disable-NetAdapterSriov](./Disable-NetAdapterSriov.md) ネットワークアダプターでSR-IOVを無効にする.

### [Disable-NetAdapterUso](Disable-NetAdapterUso.md) はネットワークアダプターの USO 属性を無効にします.

### [Disable-NetAdapterVmq] (Disable-NetAdapterVmq.md) ネットワークアダプターのVMQ機能を無効にする.

### [Enable-NetAdapter](./Enable-NetAdapter.md) ネットワークアダプターを有効にする.

### [Enable-NetAdapterIPsecOffload](./Enable-NetAdapterIPsecOffload.md) ネットワークアダプターにIPsecオフロードを有効にする.

### [Enable-NetAdapterLso](./Enable-NetAdapterLso.md) ネットワークアダプターのLSOv4やLSOv6などのLSO属性を有効にする.

### [Enable-NetAdapterPowerManagement](Enable-NetAdapterPowerManagement.md) ネットワークアダプターに特定の電力管理機能が有効になっています.

### [Enable-NetAdapterQos](./Enable-NetAdapterQos.md) ネットワークアダプター,特にDCBでQoSを有効にする.

### [Enable-NetAdapterRdma](./Enable-NetAdapterRdma.md) ネットワークアダプターで RDMAを有効にする.

### [Enable-NetAdapterRsc](./Enable-NetAdapterRsc.md) ネットワークアダプターでRSCを有効にする.

## Description
This reference provides cmdlet descriptions and syntax for all Network Adapter-specific cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

### [Disable-NetAdapter](./Disable-NetAdapter.md)

### [Disable-NetAdapterBinding](./Disable-NetAdapterBinding.md)

### [Disable-NetAdapterEncapsulatedPacketTaskOffload](./Disable-NetAdapterEncapsulatedPacketTaskOffload.md)
Disables encapsulated packet task offload.

### [Disable-NetAdapterIPsecOffload](./Disable-NetAdapterIPsecOffload.md)
Disables IPsec offload on the network adapter, so that the network adapter will not perform the per packet encryption operations.
