# Get-DnsServerGlobalNameZone について

## SYNOPSISは,DNSサーバーのGlobalName zoneの構成詳細を検索します.

## SYNTAX 

```
Get-DnsServerGlobalNameZone [-ComputerName <String>] [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>]
 [-AsJob] [<CommonParameters>]
```

## 記述 **Get-DnsServerGlobalNameZone** cmdlet は,ローカルサーバーまたは指定されたDNSサーバーのためのグローバルネームズゾーンオブジェクトのドメイン名システム (DNS) サーバを取得します.このオブジェクトには以下の設定が含まれます: 

有効 - GlobalOverLocal - PreferAAAA - AlwaysQueryServer - 有効なEDnsProbes - ブロックアップデート - 送信時間(s) - ServerQueryInterval

## 例えは,

### 例1:グローバルネームゾーン設定を取得する```
PS C:\> Get-DnsServerGlobalNameZone
```

このコマンドは,DNSサーバー **GlobalName**ゾーン設定を入手します.

# Get-DnsServerGlobalNameZone

## SYNOPSIS
Retrieves DNS server GlobalName zone configuration details.

## SYNTAX

```
Get-DnsServerGlobalNameZone [-ComputerName <String>] [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>]
 [-AsJob] [<CommonParameters>]
```

## DESCRIPTION
The **Get-DnsServerGlobalNameZone** cmdlet gets a Domain Name System (DNS) server GlobalNames zone object for the local server or a specified DNS server.
This object contains the following settings: 

- Enable
- GlobalOverLocal
- PreferAAAA
- AlwaysQueryServer
- EnableEDnsProbes
- BlockUpdates
- SendTimeout(s)
- ServerQueryInterval

## EXAMPLES

### Example 1: Get GlobalName zone settings
```
PS C:\> Get-DnsServerGlobalNameZone
```

This command gets DNS server **GlobalName** zone settings.
