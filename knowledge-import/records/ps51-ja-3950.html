# 待機イベント

## SYNOPSISは,特定のイベントが挙げられるまで待て,実行を続けます.

## SYNTAX 

```
Wait-Event [[-SourceIdentifier] <String>] [-Timeout <Int32>] [<CommonParameters>]
```

## 記述は,

   `Wait-Event`cmdlet は特定のイベントが発生するまでスクリプトまたは関数の実行を停止します.イベントが検出されたときに実行が再開します.待機をキャンセルするには,<kbd>CTRL</kbd>+<kbd>C</kbd>を押します.

この機能は,イベントの投票の代替手段として機能し,イベントに対する反応を2つの異なる方法で判断することもできます.

- イベントのサブスクリプションの **Action**パラメータを使用して - イベントが返ってくるのを待つこと,その後アクションで応答する

## 例えは,

### 例1:次のイベントを待って下さい.

この例は,次の事件が挙げられるのを待っている.

```powershell
Wait-Event
```

### 例2:指定されたソース識別子を持つイベントを待たせます

この例では,ProcessStartedのソース識別子を持つ次のイベントを待っている.

```powershell
Wait-Event -SourceIdentifier "ProcessStarted"
```

### 例3:タイムラップイベントを待たせます.

この例では,という文字を使用しています.`Wait-Event`2000ミリ秒に設定されたタイムリーイベントを待機するcmdletです.

```powershell
$Timer = New-Object Timers.Timer
$objectEventArgs = @{
    InputObject = $Timer
    EventName = 'Elapsed'
    SourceIdentifier = 'Timer.Elapsed'
}
Register-ObjectEvent @objectEventArgs
$Timer.Interval = 2000
$Timer.AutoReset = $false
$Timer.Enabled = $true
Wait-Event Timer.Elapsed
```


### 例4:指定されたタイムアウト後にイベントを待たせます.

この例では,次のイベントが起こされ,そのソース識別子が **ProcessStarted** となるが,次のイベントが起こるまで90秒まで待機する.指定された時間が終了すると,待機終了します.

```powershell
Wait-Event -SourceIdentifier "ProcessStarted" -Timeout 90
```

###英語原文###
# Wait-Event

## SYNOPSIS
Waits until a particular event is raised before continuing to run.

## SYNTAX

```
Wait-Event [[-SourceIdentifier] <String>] [-Timeout <Int32>] [<CommonParameters>]
```

## DESCRIPTION

The `Wait-Event` cmdlet suspends execution of a script or function until a particular event is
raised. Execution resumes when the event is detected. To cancel the wait, press
<kbd>CTRL</kbd>+<kbd>C</kbd>.

This feature provides an alternative to polling for an event. It also allows you to determine the
response to an event in two different ways:

- using the **Action** parameter of the event subscription
- waiting for an event to return and then respond with an action

## EXAMPLES

### Example 1: Wait for the next event

This example waits for the next event that is raised.

```powershell
Wait-Event
```

### Example 2: Wait for an event with a specified source identifier

This example waits for the next event that has a source identifier of ProcessStarted.

```powershell
Wait-Event -SourceIdentifier "ProcessStarted"
```

### Example 3: Wait for a timer elapsed event

This example uses the `Wait-Event` cmdlet to wait for a timer event that's set for 2000
milliseconds.

```powershell
$Timer = New-Object Timers.Timer
$objectEventArgs = @{
    InputObject = $Timer
    EventName = 'Elapsed'
    SourceIdentifier = 'Timer.Elapsed'
}
Register-ObjectEvent @objectEventArgs
$Timer.Interval = 2000
$Timer.AutoReset = $false
$Timer.Enabled = $true
Wait-Event Timer.Elapsed
```

```Output
ComputerName     :
RunspaceId       : bb560b14-ff43-48d4-b801-5adc31bbc6fb
EventIdentifier  : 1
Sender           : System.Timers.Timer
SourceEventArgs  : System.Timers.ElapsedEventArgs
SourceArgs       : {System.Timers.Timer, System.Timers.ElapsedEventArgs}
SourceIdentifier : Timer.Elapsed
TimeGenerated    : 4/23/2020 2:30:37 PM
MessageData      :
```

### Example 4: Wait for an event after a specified timeout

This example waits up to 90 seconds for the next event that is raised and that has a source
identifier of **ProcessStarted**. If the specified time expires, the wait ends.

```powershell
Wait-Event -SourceIdentifier "ProcessStarted" -Timeout 90
```

## PARAMETERS

### -SourceIdentifier

Specifies the source identifier that this cmdlet waits for events.
By default, `Wait-Event` waits for any event.

```yaml
Type: System.String
Parameter Sets: (All)
Aliases:

Required: False
Position: 0
Default value: None
Accept pipeline input: True (ByPropertyName)
Accept wildcard characters: False
```

### -Timeout

Specifies the maximum time, in seconds, that `Wait-Event` waits for the event to occur. The default,
-1, waits indefinitely. The timing starts when you submit the `Wait-Event` command.

If the specified time is exceeded, the wait ends and the command prompt returns, even if the event
has not been raised. No error message is displayed.

```yaml

Required: False

```
