# セットアップxパッケージをリセットする

## シノプシスです.

Windows アプリを元の設定に戻します.

## SYNTAX 

```
Reset-AppxPackage
 [-Package] <string>
 [-WhatIf]
 [-Confirm]
 [<CommonParameters>]
```

## 記述は,

   `Reset-AppxPackage`cmdlet は,アプリを元の設定にリセットし,アプリは新しくインストールされたアプリとして反応します.

アプリをリセットした後,アプリによる最初の提示はユーザー入力に提示されます.

## 例えは,

### 例1:アプリパッケージをリセットする

```powershell
Reset-AppxPackage -Package publisher.package1_1.0.0.0_neutral__8wekyb3d8bbwe
```

このcmdletは,  をリセットします.`publisher.package1_1.0.0.0_neutral__8wekyb3d8bbwe`アプリケーションは元の設定に戻ります.

# Reset-AppxPackage

## SYNOPSIS

Restores the Windows app to its initial configuration.

## SYNTAX

```
Reset-AppxPackage
 [-Package] <string>
 [-WhatIf]
 [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

The `Reset-AppxPackage` cmdlet resets the app to its original settings, and the app will react
as a freshly installed app.

After resetting the app, any initial prompts by the app will be prompted for user input.

## EXAMPLES

### Example 1: Reset app package

```powershell
Reset-AppxPackage -Package publisher.package1_1.0.0.0_neutral__8wekyb3d8bbwe
```

This cmdlet resets the `publisher.package1_1.0.0.0_neutral__8wekyb3d8bbwe` application back to
its original settings.
