# NetEventPacketCapture Module について

## この参照の説明は,すべてのNetEventPacketCapture cmdlets のcmdlet の説明と構文を提供します.この参照は,cmdlet の初めの動詞に基づいて,アルファベット順で cmdlets をリストします.

## NetEventPacketCapture Cmdlets は,Cmdlets を使用する

### [Add-NetEventNetworkAdapter](./Add-NetEventNetworkAdapter.md) プロバイダーにフィルターとしてネットワークアダプターを追加します.

### [Add-NetEventPacketCaptureProvider](./Add-NetEventPacketCaptureProvider.md) は,リモートパケットキャプチャプロバイダーを追加します.

### [Add-NetEventProvider](./Add-NetEventProvider.md) セッションにETWプロバイダを追加します.

### [Add-NetEventVFPProvider](Add-NetEventVFPProvider.md) ネットワークイベントの VFP プロバイダーを作成します.

### [Add-NetEventVmNetworkAdapter](Add-NetEventVmNetworkAdapter.md) プロバイダにフィルターとして仮想ネットワークアダプターを追加します.

### [Add-NetEventVmSwitch](./Add-NetEventVmSwitch.md) プロバイダのフィルターとしてHyper-V仮想スイッチを追加します.

### [Add-NetEventVmSwitchProvider](Add-NetEventVmSwitchProvider.md) ネットワークイベントのための仮想マシンスイッチプロバイダを作成します.

### [Add-NetEventWFPCaptureProvider](Add-NetEventWFPCaptureProvider.md) は,WFPのキャプチャプロバイダを作成します.

### [Get-NetEventNetworkAdapter](./Get-NetEventNetworkAdapter.md) は,遠隔パケットキャプチャプロバイダーに関連したネットワークアダプターを取得します.

### [Get-NetEventPacketCaptureProvider](./Get-NetEventPacketCaptureProvider.md) は,リモートパケットキャプチャプロバイダを表示しています.

### [Get-NetEventProvider] (/Get-NetEventProvider.md) は,コンピュータに存在しているETWプロバイダーやイベントとパケットキャプチャセッションに関連したETWプロバイダーを表示します.

### [Get-NetEventSession](./Get-NetEventSession.md) はネットワークイベントセッションを入手します.

### [Get-NetEventVFPProvider] (Get-NetEventVFPProvider.md) はネットワークイベントの VFP プロバイダーを入手しています.

### [Get-NetEventVmNetworkAdapter](Get-NetEventVmNetworkAdapter.md) は,プロバイダから仮想ネットワークアダプターを入手する.

### [Get-NetEventVmSwitch](./Get-NetEventVmSwitch.md) は,プロバイダからHyper-V仮想スイッチを入手します.

### [Get-NetEventVmSwitchProvider](Get-NetEventVmSwitchProvider.md) はネットワークイベントのための仮想マシンスイッチプロバイダーを取得します.

### [Get-NetEventWFPCaptureProvider](Get-NetEventWFPCaptureProvider.md) は,ローカルまたはリモート WFPキャプチャプロバイダの設定の設定を表示します.

### [New-NetEventSession](./New-NetEventSession.md) はネットワークイベントセッションを作成します.

### [Remove-NetEventNetworkAdapter](./Remove-NetEventNetworkAdapter.md) プロバイダーに関連したネットワークアダプターを削除します.

### [Remove-NetEventPacketCaptureProvider](./Remove-NetEventPacketCaptureProvider.md) は,リモートパケットキャプチャプロバイダを削除し,設定を削除します.

### [Remove-NetEventProvider](./Remove-NetEventProvider.md) セッションからETWプロバイダを削除します.

### [Remove-NetEventSession](./Remove-NetEventSession.md) ネットワークイベントセッションを削除します.

### [Remove-NetEventVFPProvider] (Remove-NetEventVFPProvider.md) ネットワークイベントのVFPプロバイダを削除する.

### [Remove-NetEventVmNetworkAdapter](Remove-NetEventVmNetworkAdapter.md) プロバイダから仮想ネットワークアダプターを削除します.

### [Remove-NetEventVmSwitch](./Remove-NetEventVmSwitch.md) は,プロバイダーからHyper-V仮想スイッチを削除します.

### [Remove-NetEventVmSwitchProvider] (Remove-NetEventVmSwitchProvider.md) ネットワークイベントの仮想マシンスイッチプロバイダを削除します.

### [Remove-NetEventWFPCaptureProvider] (Remove-NetEventWFPCaptureProvider.md) は,ローカルまたはリモート WFPキャプチャプロバイダを削除します.

### [Set-NetEventPacketCaptureProvider](./Set-NetEventPacketCaptureProvider.md) は,リモートパケットキャプチャプロバイダの設定を変更します.

### [Set-NetEventProvider](./Set-NetEventProvider.md) は,ETWプロバイダの設定を変更します.

### [Set-NetEventSession](./Set-NetEventSession.md) はネットワークイベントセッションを修正します.

### [Set-NetEventVFPProvider] (Set-NetEventVFPProvider.md) は,ネットワークイベントの VFP プロバイダーを修正する.

### [Set-NetEventVmSwitchProvider](Set-NetEventVmSwitchProvider.md) は,ネットワークイベントの仮想マシンスイッチプロバイダーを修正します.

### [Set-NetEventWFPCaptureProvider](Set-NetEventWFPCaptureProvider.md) は,WFPキャプチャプロバイダの構成を変更します.

### [Start-NetEventSession](./Start-NetEventSession.md) ネットワークイベントセッションのイベントとパケットキャプチャを起動します.

### [Stop-NetEventSession](./Stop-NetEventSession.md) ネットワークイベントセッションのためにイベントやパケットキャプチャを停止します.

# NetEventPacketCapture Module

## Description
This reference provides cmdlet descriptions and syntax for all NetEventPacketCapture cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

## NetEventPacketCapture Cmdlets

### [Add-NetEventNetworkAdapter](./Add-NetEventNetworkAdapter.md)
Adds a network adapter as a filter on a provider.

### [Add-NetEventPacketCaptureProvider](./Add-NetEventPacketCaptureProvider.md)

### [Add-NetEventProvider](./Add-NetEventProvider.md)
Adds an ETW provider to a session.

### [Add-NetEventVFPProvider](Add-NetEventVFPProvider.md)
