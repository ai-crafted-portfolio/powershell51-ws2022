## 記述 **Enable-NetAdapterChecksumOffload** cmdlet は,ネットワークアダプターでチェックサムオフロードを可能にします.指定された場合,IPv4,TCPv4またはTCPv6 は,送信,受信,または両方の方向で有効にできます.デフォルトでは,すべてのチェックサムが両方の方向で有効です.物理的なネットワークアダプターは,チェックサムオフロードを異なるチェックサムオフロードを持っています.そのチェックサム計算は,メインプロセッサではなくネットワークアダプターで発生します. これによりプロセッサ利用が減少し,ネットワーク[U+541E]吐量を増加できます.この cmdlet は,IPv4,TCPv4,TCPv6,UDPv4,UDPv6を含む様々なチェックサムオフロード設定を有効にします.チェックサムオフロードは,ステートレスサイドスキャッシングを含む他のワークロードで取得されます.(RSS),受領セグメントコアレス (RSC) や,大発送オフロード (LSO) を行う.

## 例えは

### 例1:すべてのネットワークアダプターでIPv4チェックサムオフロードを有効にします.```
PS C:\> Enable-NetAdapterChecksumOffload -Name "*" -TcpIPv4 -UdpIPv4 -IpIPv4
```

このコマンドは,すべての可視ネットワークアダプターのすべてのIPv4チェックサムオフロードを有効にし,ネットワークアダプターを再起動します.

### 例2:すべてのネットワークアダプターですべてのチェックサムオフロードを有効にします.```
PS C:\> Enable-NetAdapterChecksumOffload -Name "*"
```

このコマンドは,すべての可視ネットワークアダプターのチェックサムオフロードを有効にし,ネットワークアダプターを再起動します.

# Enable-NetAdapterChecksumOffload

## SYNOPSIS
Enables checksum offloads on the network adapter.

## SYNTAX

## DESCRIPTION
The **Enable-NetAdapterChecksumOffload** cmdlet enables checksum offloads on the network adapter.
When specified IPv4, TCPv4, or TCPv6 can be enabled in transmission, receive, or both directions.
By default all checksums are enabled in both directions.
Physical network adapters have various checksum offloads in which the checksum calculations occur in the network adapter and not in the main processor.
This reduces processor utilization and can increase network throughput.
This cmdlet enables the various checksum offload settings, including IPv4, TCPv4, TCPv6, UDPv4, and UDPv6.
Checksum offloading is also required for other stateless offloads to work including receive side scaling (RSS), receive segment coalescing (RSC), and large send offload (LSO).

## EXAMPLES

### Example 1: Enable IPv4 checksum offloads on all network adapters
```
PS C:\> Enable-NetAdapterChecksumOffload -Name "*" -TcpIPv4 -UdpIPv4 -IpIPv4
```

This command enables all IPv4 checksum offloads on all visible network adapters and restarts the network adapters.

### Example 2: Enable all checksum offloads on all network adapters
```
PS C:\> Enable-NetAdapterChecksumOffload -Name "*"
```

This command enables all checksum offloads on all visible network adapters and restarts the network adapters.
