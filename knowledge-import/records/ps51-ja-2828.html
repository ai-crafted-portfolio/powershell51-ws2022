# 集計された作業を予定する作業を集める

## SYNOPSISは,失敗クラスターのスケジュールタスクをクラスタに集める.

## SYNTAXは,のシンタックスです.

```
Get-ClusteredScheduledTask [[-TaskName] <String>] [[-Cluster] <String>] [[-TaskType] <ClusterTaskTypeEnum>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## 記述 **Get-ClusteredScheduledTask** cmdlet は,失敗クラスターに登録されているクラスターされた予定されたタスクを集約します.タスク名またはタスクタイプを指定できます.

Windows Server(R) 2012 タスクスケジューラーに関する詳細については, [タスクスケジューラー概要]の参照を参照してください.https://technet.microsoft.com/en-us/library/cc721871.aspx) について,TechNet図書館で話題にしました.http://technet.microsoft.com/en-us/library/cc721871.aspx.

## 例えは

### 例1: 予定された作業を入手する```
PS C:\> Get-ClusteredScheduledTask -TaskName "Task14" -Cluster "Cluster73"
```

このコマンドは,Cluster73と呼ばれるクラスタ上のタスク14というタスクを獲得します.

###英語原文###
# Get-ClusteredScheduledTask

## SYNOPSIS
Gets clustered scheduled tasks for a failover cluster.

## SYNTAX

```
Get-ClusteredScheduledTask [[-TaskName] <String>] [[-Cluster] <String>] [[-TaskType] <ClusterTaskTypeEnum>]
 [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## DESCRIPTION
The **Get-ClusteredScheduledTask** cmdlet gets the clustered scheduled tasks registered on a failover cluster.
You can specify task name or task type.

For more information about the Windows Server(R) 2012 Task Scheduler, see the [Task Scheduler Overview](https://technet.microsoft.com/en-us/library/cc721871.aspx) topic in the TechNet Library at http://technet.microsoft.com/en-us/library/cc721871.aspx.

## EXAMPLES

### Example 1: Get scheduled tasks
```
PS C:\> Get-ClusteredScheduledTask -TaskName "Task14" -Cluster "Cluster73"
```

This command gets the task named Task14 on the cluster named Cluster73.
