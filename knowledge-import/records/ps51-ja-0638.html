## 記述は,

**Remove-MpPreference** cmdletは,多値性属性 (例えば,除外および保護されたフォルダー) の値を削除し,Windows Defenderの設定をデフォルト値に戻します.

## 例えは

### 例1

```powershell
Remove-MpPreference -ExclusionPath "C:\Temp"
```

この例では,C:\Tempフォルダを排除リストから削除します.

### 例2

```powershell
Remove-MpPreference -AttackSurfaceReductionOnlyExclusions "C:\Windows\App.exe"
```

この例では,CドライブにあるWindowsフォルダの app.exe ファイルのみを除外しています.
