# BitsTransfer Module について

## この参照は,すべてのBITS (Brainground Intelligent Transfer Management) 特定のcmdletのcmdletの説明と構文を提供します.この参照は,cmdletの初めの動詞に基づいてアルファベット順でcmdletをリストします.

## BitsTransfer Cmdlets を転送する

### [BitsFile-Add-BitsFile] (/Add-BitsFile.md) は,既存のBITS転送作業に1つまたは複数のファイルを追加します.

### [Complete-BitsTransfer](./Complete-BitsTransfer.md) はBITS転送作業を完了します.

### [Get-BitsTransfer](./Get-BitsTransfer.md) は,既存のBITS転送作業の関連BitsJobオブジェクトを取得します.

### [Remove-BitsTransfer](./Remove-BitsTransfer.md) は,BITS転送の仕事をキャンセルします.

### [Resume-BitsTransfer](./Resume-BitsTransfer.md) は,BITS転送の仕事を再開する.

### [Set-BitsTransfer](./Set-BitsTransfer.md) は,既存のBITS転送作業のプロパティを修正する.

### [Start-BitsTransfer](./Start-BitsTransfer.md) はBITS転送の仕事を作成します.

### [Suspend-BitsTransfer](./Suspend-BitsTransfer.md) はBITS転送の仕事を中止しています.
###英語原文###
# BitsTransfer Module

## Description
This reference provides cmdlet descriptions and syntax for all Background Intelligent Transfer Management (BITS)-specific cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

## BitsTransfer Cmdlets

### [Add-BitsFile](./Add-BitsFile.md)
Adds one or more files to an existing BITS transfer job.

### [Complete-BitsTransfer](./Complete-BitsTransfer.md)
Completes a BITS transfer job.

### [Get-BitsTransfer](./Get-BitsTransfer.md)
Gets the associated BitsJob object for an existing BITS transfer job.

### [Remove-BitsTransfer](./Remove-BitsTransfer.md)
Cancels a BITS transfer job.

### [Resume-BitsTransfer](./Resume-BitsTransfer.md)
Resumes a BITS transfer job.

### [Set-BitsTransfer](./Set-BitsTransfer.md)
Modifies the properties of an existing BITS transfer job.

### [Start-BitsTransfer](./Start-BitsTransfer.md)
Creates a BITS transfer job.

### [Suspend-BitsTransfer](./Suspend-BitsTransfer.md)
Suspends a BITS transfer job.
