# SecureBoot モジュールは

## この参照の説明は,すべてのSecure Boot-specific cmdletsのcmdletの説明と構文を提供します.この参照は,アルファベティ順でcmdletsをリストします.

## SecureBoot Cmdlets について

### [Confirm-SecureBootUEFI](./Confirm-SecureBootUEFI.md) ローカルコンピュータのSecure Boot statusをチェックすることでSecure Bootが有効になっていることを確認します.

### [Format-SecureBootUEFI](./Format-SecureBootUEFI.md) 証明書またはハッシュをコンテンツオブジェクトにフォーマットして返却され,署名準備ができているファイルを作成します.

### [Get-SecureBootPolicy](./Get-SecureBootPolicy.md) は,出版社 GUID と Secure Boot 設定ポリシー のポリシーバージョンを入手します.

### [Get-SecureBootUEFI](./Get-SecureBootUEFI.md) は,Secure Boot に関連する UEFI 変数値を取得します.

### [Set-SecureBootUEFI](./Set-SecureBootUEFI.md) は,Secure Bootに関連する UEFI変数を設定しています.
###英語原文###
# SecureBoot Module

## Description
This reference provides cmdlet descriptions and syntax for all Secure Boot-specific cmdlets. It lists the cmdlets in alphabetical order.

## SecureBoot Cmdlets

### [Confirm-SecureBootUEFI](./Confirm-SecureBootUEFI.md)
Confirms that Secure Boot is enabled by checking the Secure Boot status on the local computer.

### [Format-SecureBootUEFI](./Format-SecureBootUEFI.md)
Formats certificates or hashes into a content object that is returned and creates a file that is ready to be signed.

### [Get-SecureBootPolicy](./Get-SecureBootPolicy.md)
Gets the publisher GUID and the policy version of the Secure Boot configuration policy.

### [Get-SecureBootUEFI](./Get-SecureBootUEFI.md)
Gets the UEFI variable values related to Secure Boot.

### [Set-SecureBootUEFI](./Set-SecureBootUEFI.md)
Sets the Secure Boot-related UEFI variables.
