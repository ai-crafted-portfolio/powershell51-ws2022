# AppvClient Module について

## 次の説明リストには,Microsoft Application Virtualization (App-V) クライアント cmdletsのサポートトピックへのリンクが含まれています.

## AppvClient Cmdlets は,Cmdlets を使用する

### [Add-AppvClientConnectionGroup](./Add-AppvClientConnectionGroup.md) は複数のパッケージの構成を作成します.

### [Add-AppvClientPackage](./Add-AppvClientPackage.md) は,App-Vクライアントを実行しているコンピュータにパッケージを追加します.

### [Add-AppvPublishingServer](./Add-AppvPublishingServer.md) は,App-Vクライアントを実行しているコンピュータに出版サーバーを追加します.

### [Disable-Appv](./Disable-Appv.md) はApp-Vサービスを無効にする.

### [Disable-AppvClientConnectionGroup](./Disable-AppvClientConnectionGroup.md) は,App-Vクライアントを実行しているコンピュータの接続グループを無効にする.

### [Enable-Appv](./Enable-Appv.md) は,App-Vサービスを有効にする.

### [Enable-AppvClientConnectionGroup](./Enable-AppvClientConnectionGroup.md) アプリケーション-V クライアントを実行しているコンピュータで実行されている接続グループを有効にする.

### [Get-AppvClientApplication](./Get-AppvClientApplication.md) は,App-Vクライアントパッケージの一部であるアプリケーションを返します.

### [Get-AppvClientConfiguration](./Get-AppvClientConfiguration.md) は,App-Vクライアントの設定を返します.

### [Get-AppvClientConnectionGroup](./Get-AppvClientConnectionGroup.md) は,App-V接続グループオブジェクトを返します.

### [Get-AppvClientMode](./Get-AppvClientMode.md) は,App-V クライアントのモードを表示します.

### [Get-AppvClientPackage](./Get-AppvClientPackage.md) は,App-Vクライアントパッケージを返却します.

### [Get-AppvPublishingServer](./Get-AppvPublishingServer.md) は,App-V Serverのオブジェクトを返します.

### [Get-AppvStatus] (/Get-AppvStatus.md) は,App-Vサービスの状態を表示する.

### [Get-AppvVirtualProcess](./Get-AppvVirtualProcess.md) は,コンピュータで実行されている仮想プロセスを表示します.

### [Mount-AppvClientConnectionGroup](./Mount-AppvClientConnectionGroup.md) は,パッケージの内容をローカルディスクにストリームします.

### [Mount-AppvClientPackage](./Mount-AppvClientPackage.md) は,App-Vキャッシュにパッケージをロードします.

### [Publish-AppvClientPackage](./Publish-AppvClientPackage.md) はApp-Vパッケージを公開する.

### [Remove-AppvClientConnectionGroup](./Remove-AppvClientConnectionGroup.md) クライアント上のApp-V接続グループを削除します.

### [Remove-AppvClientPackage](./Remove-AppvClientPackage.md) パッケージをコンピュータから削除します.

### [Remove-AppvPublishingServer](./Remove-AppvPublishingServer.md) は,App-Vの出版サーバを削除する.

### [Repair-AppvClientConnectionGroup](./Repair-AppvClientConnectionGroup.md) 接続グループのためのユーザーパッケージ設定をリセットします.

### [Repair-AppvClientPackage](./Repair-AppvClientPackage.md) パッケージのユーザー設定をリセットします.

### [Send-AppvClientReport](./Send-AppvClientReport.md) はクライアントからの報告データを送信します.

### [Set-AppvClientConfiguration](./Set-AppvClientConfiguration.md) は,App-Vクライアントに構成設定を適用します.

### [Set-AppvClientMode](./Set-AppvClientMode.md) クライアントが実行するモードを設定します.

### [Set-AppvClientPackage](./Set-AppvClientPackage.md) は,App-Vクライアントパッケージを構成する.

### [Set-AppvPublishingServer](./Set-AppvPublishingServer.md) は,App-V出版サーバーのプロパティを修正する.

### [Start-AppvVirtualProcess](./Start-AppvVirtualProcess.md) 仮想プロセスを起動します.

### [Stop-AppvClientConnectionGroup](./Stop-AppvClientConnectionGroup.md) は,接続グループの共有仮想環境をシャットダウンします.

### [Stop-AppvClientPackage](./Stop-AppvClientPackage.md) は指定されたパッケージの仮想環境をシャットダウンします.

### [Sync-AppvPublishingServer](./Sync-AppvPublishingServer.md) は,App-V 出版リフレッシュ操作を開始します.

### [Unpublish-AppvClientPackage](./Unpublish-AppvClientPackage.md) パッケージの拡張点を削除します.
###英語原文###
# AppvClient Module

## Description
The following list contains links to the help topics for the Microsoft Application Virtualization (App-V) Client cmdlets.

## AppvClient Cmdlets

### [Add-AppvClientConnectionGroup](./Add-AppvClientConnectionGroup.md)
Creates a composition of multiple packages.

### [Add-AppvClientPackage](./Add-AppvClientPackage.md)
Adds a package to a computer running the App-V client.

### [Add-AppvPublishingServer](./Add-AppvPublishingServer.md)
Adds a publishing server for the computer that runs the App-V client.

### [Disable-Appv](./Disable-Appv.md)
Disables the App-V service.

### [Disable-AppvClientConnectionGroup](./Disable-AppvClientConnectionGroup.md)
Disables a connection group on the computer running the App-V client.

### [Enable-Appv](./Enable-Appv.md)
Enables the App-V service.

### [Enable-AppvClientConnectionGroup](./Enable-AppvClientConnectionGroup.md)
Enables a running connection group on the computer running the App-V client.

### [Get-AppvClientApplication](./Get-AppvClientApplication.md)
Returns applications that are part of App-V Client Packages.

### [Get-AppvClientConfiguration](./Get-AppvClientConfiguration.md)
Returns the configuration for the App-V client.

### [Get-AppvClientConnectionGroup](./Get-AppvClientConnectionGroup.md)
Returns an App-V connection group object.

### [Get-AppvClientMode](./Get-AppvClientMode.md)
Displays the mode for the App-V Client.

### [Get-AppvClientPackage](./Get-AppvClientPackage.md)
Returns App-V Client Packages.

### [Get-AppvPublishingServer](./Get-AppvPublishingServer.md)
Returns App-V Server objects.

### [Get-AppvStatus](./Get-AppvStatus.md)
Gets the status of the App-V service.

### [Get-AppvVirtualProcess](./Get-AppvVirtualProcess.md)
Displays the virtual processes running on a computer.

### [Mount-AppvClientConnectionGroup](./Mount-AppvClientConnectionGroup.md)
Streams the contents of packages to the local disk.

### [Mount-AppvClientPackage](./Mount-AppvClientPackage.md)
Loads a package into the App-V cache.

### [Publish-AppvClientPackage](./Publish-AppvClientPackage.md)
Publishes the App-V package.

### [Remove-AppvClientConnectionGroup](./Remove-AppvClientConnectionGroup.md)
Deletes an App-V connection group on the client.

### [Remove-AppvClientPackage](./Remove-AppvClientPackage.md)
Removes the package from a computer.

### [Remove-AppvPublishingServer](./Remove-AppvPublishingServer.md)
Removes an App-V publishing server.

### [Repair-AppvClientConnectionGroup](./Repair-AppvClientConnectionGroup.md)
Resets the user package settings for the connection group.

### [Repair-AppvClientPackage](./Repair-AppvClientPackage.md)
Resets the user settings of a package.

### [Send-AppvClientReport](./Send-AppvClientReport.md)
Sends reporting data from the client.

### [Set-AppvClientConfiguration](./Set-AppvClientConfiguration.md)
Applies configuration settings to the App-V Client.

### [Set-AppvClientMode](./Set-AppvClientMode.md)
Sets the mode in which the client runs.

### [Set-AppvClientPackage](./Set-AppvClientPackage.md)
Configures an App-V Client Package.

### [Set-AppvPublishingServer](./Set-AppvPublishingServer.md)
Modifies properties of an App-V Publishing Server.

### [Start-AppvVirtualProcess](./Start-AppvVirtualProcess.md)
Starts a virtual process.

### [Stop-AppvClientConnectionGroup](./Stop-AppvClientConnectionGroup.md)
Shuts down the shared virtual environment of a connection group.

### [Stop-AppvClientPackage](./Stop-AppvClientPackage.md)
Shuts down virtual environments for specified packages.

### [Sync-AppvPublishingServer](./Sync-AppvPublishingServer.md)
Initiates the App-V Publishing Refresh operation.

### [Unpublish-AppvClientPackage](./Unpublish-AppvClientPackage.md)
Removes the extension points for packages.
