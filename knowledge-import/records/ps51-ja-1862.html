# MSMQ モジュール

## この参照は,MSMQの特定のcmdletのすべてのためのcmdletの説明と構文を提供します.この参照は,cmdletの初めの動詞に基づいてアルファベット順でcmdletsをリストします.

## MSMQ Cmdlets について

### [Clear-MsmqOutgoingQueue](./Clear-MsmqOutgoingQueue.md) は,出かけするキューをクリアします.

### [Clear-MsmqQueue](./Clear-MsmqQueue.md) 排列をクリアする.

### [Enable-MsmqCertificate](./Enable-MsmqCertificate.md) は,アクティブディレクトリドメインサービスで証明書を登録します.

### [Get-MsmqCertificate](./Get-MsmqCertificate.md) は,アクティブディレクトリドメインサービスで登録された証明書を取得します.

### [Get-MsmqOutgoingQueue](./Get-MsmqOutgoingQueue.md) は,送信されたメッセージのキューを表示します.

### [Get-MsmqQueue](./Get-MsmqQueue.md) はメッセージのキューを入手します.

### [Get-MsmqQueueACL](./Get-MsmqQueueACL.md) は,アクセス管理リストのキューを表示します.

### [Get-MsmqQueueManager](./Get-MsmqQueueManager.md) はキューマネージャーを獲得する.

### [Get-MsmqQueueManagerACL](./Get-MsmqQueueManagerACL.md) は,地元のキューマネージャーのアクセス制御リストを取得します.

### [Move-MsmqMessage](./Move-MsmqMessage.md) 副列間のメッセージ,またはメイン列とサブ列間のメッセージを移動します.

### [New-MsmqMessage](./New-MsmqMessage.md) はメッセージオブジェクトを作成します.

### [New-MsmqQueue](./New-MsmqQueue.md) は,公的または私的なキューを作成します.

### [Receive-MsmqQueue](./Receive-MsmqQueue.md) 列から破壊的な読み聞かせをします.

### [MsmqCertificate.md]は,個人証明書を取り除きます.

### [MsmqQueue-Remove-MsmqQueue.md]は,列を削除します.

### [Resume-MsmqOutgoingQueue](./Resume-MsmqOutgoingQueue.md) 復習する排列の復習.

### [Send-MsmqQueue](./Send-MsmqQueue.md) は,遠隔のキューにテストメッセージを送信します.

### [Set-MsmqQueue](./Set-MsmqQueue.md) 列の属性を設定する.

### [Set-MsmqQueueACL](./Set-MsmqQueueACL.md) は,キューのアクセス権を変更します.

### [Set-MsmqQueueManager](./Set-MsmqQueueManager.md) は,キューマネージャーを構成します.

### [Set-MsmqQueueManagerACL](./Set-MsmqQueueManagerACL.md) は,キューマネージャーのアクセス権を変更します.

### [Suspend-MsmqOutgoingQueue](./Suspend-MsmqOutgoingQueue.md) 出発する列を休止する.
###英語原文###
# MSMQ Module

## Description
This reference provides cmdlet descriptions and syntax for all MSMQ-specific cmdlets. It lists the cmdlets in alphabetical order based on the verb at the beginning of the cmdlet.

## MSMQ Cmdlets

### [Clear-MsmqOutgoingQueue](./Clear-MsmqOutgoingQueue.md)
Clears outgoing queues.

### [Clear-MsmqQueue](./Clear-MsmqQueue.md)
Clears queues.

### [Enable-MsmqCertificate](./Enable-MsmqCertificate.md)
Registers a certificate with Active Directory Domain Services.

### [Get-MsmqCertificate](./Get-MsmqCertificate.md)
Gets certificates registered in Active Directory Domain Services.

### [Get-MsmqOutgoingQueue](./Get-MsmqOutgoingQueue.md)
Gets outgoing message queues.

### [Get-MsmqQueue](./Get-MsmqQueue.md)
Gets message queues.

### [Get-MsmqQueueACL](./Get-MsmqQueueACL.md)
Gets queue access control lists.

### [Get-MsmqQueueManager](./Get-MsmqQueueManager.md)
Gets a queue manager.

### [Get-MsmqQueueManagerACL](./Get-MsmqQueueManagerACL.md)
Gets access control lists for the local queue manager.

### [Move-MsmqMessage](./Move-MsmqMessage.md)
Moves messages between subqueues or between the main queue and a subqueue.

### [New-MsmqMessage](./New-MsmqMessage.md)
Creates a message object.

### [New-MsmqQueue](./New-MsmqQueue.md)
Creates public or private queues.

### [Receive-MsmqQueue](./Receive-MsmqQueue.md)
Does a destructive read from a queue.

### [Remove-MsmqCertificate](./Remove-MsmqCertificate.md)
Removes personal certificates.

### [Remove-MsmqQueue](./Remove-MsmqQueue.md)
Deletes queues.

### [Resume-MsmqOutgoingQueue](./Resume-MsmqOutgoingQueue.md)
Resumes outgoing queues.

### [Send-MsmqQueue](./Send-MsmqQueue.md)
Sends a test message to remote queues.

### [Set-MsmqQueue](./Set-MsmqQueue.md)
Sets properties of queues.

### [Set-MsmqQueueACL](./Set-MsmqQueueACL.md)
Modifies the access rights of queues.

### [Set-MsmqQueueManager](./Set-MsmqQueueManager.md)
Configures the queue manager.

### [Set-MsmqQueueManagerACL](./Set-MsmqQueueManagerACL.md)
Modifies the access rights of a queue manager.

### [Suspend-MsmqOutgoingQueue](./Suspend-MsmqOutgoingQueue.md)
Pauses outgoing queues.
