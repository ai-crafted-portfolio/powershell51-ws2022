###日本語訳###
# ADCSA管理モジュール

## このテーマの説明は,アクティブディレクトリ証明書サービス (AD CS) 認証機関 (CA) の役割サービスを管理するために使用される Windows PowerShell(R) cmdlet の簡潔な説明が含まれています.表内の各 cmdlet は,その cmdlet に関する追加の情報にリンクされています.

## ADCSA管理 Cmdlets

### [Add-CAAuthorityInformationAccess](./Add-CAAuthorityInformationAccess.md) は,認証機関のためにAIAまたはOCSPを構成します.

### [Add-CACrlDistributionPoint](./Add-CACrlDistributionPoint.md) は,AD CSが認証撤回を公表するCRL配分点 URIを追加します.

### [Add-CATemplate](./Add-CATemplate.md) は,CAに証明書テンプレートを追加します.

### [Backup-CARoleService](./Backup-CARoleService.md) は,CAデータベースとプライベートキー情報をバックアップします.

### [CAAttestationIdentityKeyInfo] (Confirm-CAAttestationIdentityKeyInfo.md) 確認する) 地方CAがアイデンティティキー認証の安全なハードウェアを信頼しているか確認する.

### [CAEndorsementKeyInfo] (Confirm-CAEndorsementKeyInfo.md) 鍵認証のために,地元のCAが安全なハードウェアを信頼しているかチェックします.

### [Get-CAAuthorityInformationAccess](./Get-CAAuthorityInformationAccess.md) は,CA属性のAIA拡張子に設定されたAIAとOCSP URI情報を取得します.

### [Get-CACrlDistributionPoint](./Get-CACrlDistributionPoint.md) は,CAプロパティのCDP拡張子に設定されているすべての位置を取得します.

### [Get-CATemplate](./Get-CATemplate.md) 証明書の発行のためにCAに設定されたテンプレートのリストを取得します.

### [Remove-CAAuthorityInformationAccess](./Remove-CAAuthorityInformationAccess.md) は,認証機関に設定されたAIA拡張子からAIAまたはOCSP URIを削除します.

### [Remove-CACrlDistributionPoint](./Remove-CACrlDistributionPoint.md) は,CAからCRL分布点 (CDP) のURIを削除します.

### [Remove-CATemplate](./Remove-CATemplate.md) 証明書の発行のために設定されたCAからテンプレートを削除します.

### [Restore-CARoleService](./Restore-CARoleService.md) は,CAデータベースとプライベートキー情報を復元します.
###英語原文###
# ADCSAdministration Module

## Description
This topic contains the brief descriptions of the Windows PowerShell(R) cmdlets that are for use in administering the Active Directory Certificate Services (AD CS) certification authority (CA) role service. Each cmdlet in the table is linked to additional information about that cmdlet.

## ADCSAdministration Cmdlets

### [Add-CAAuthorityInformationAccess](./Add-CAAuthorityInformationAccess.md)
Configures the AIA or OCSP for a certification authority.

### [Add-CACrlDistributionPoint](./Add-CACrlDistributionPoint.md)
Adds a CRL distribution point URI where AD CS publishes certification revocations.

### [Add-CATemplate](./Add-CATemplate.md)
Adds a certificate template to the CA.

### [Backup-CARoleService](./Backup-CARoleService.md)
Backs up the CA database and private key information.

### [Confirm-CAAttestationIdentityKeyInfo](Confirm-CAAttestationIdentityKeyInfo.md)
Checks whether the local CA trusts secure hardware for identity key attestation.

### [Confirm-CAEndorsementKeyInfo](Confirm-CAEndorsementKeyInfo.md)
Checks whether the local CA trusts secure hardware for key attestation.

### [Get-CAAuthorityInformationAccess](./Get-CAAuthorityInformationAccess.md)
Gets the AIA and OCSP URI information set on the AIA extension of the CA properties.

### [Get-CACrlDistributionPoint](./Get-CACrlDistributionPoint.md)
Gets all the locations set on the CDP extension of the CA properties.

### [Get-CATemplate](./Get-CATemplate.md)
Gets the list of templates set on the CA for issuance of certificates.

### [Remove-CAAuthorityInformationAccess](./Remove-CAAuthorityInformationAccess.md)
Removes AIA or OCSP URI from the AIA extension set on the certification authority.

### [Remove-CACrlDistributionPoint](./Remove-CACrlDistributionPoint.md)
Removes the URI for the CRL distribution point (CDP) from the CA.

### [Remove-CATemplate](./Remove-CATemplate.md)
Removes the templates from the CA which were set for issuance of certificates.

### [Restore-CARoleService](./Restore-CARoleService.md)
Restores the CA database and private key information.
