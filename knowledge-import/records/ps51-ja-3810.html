# セットタイムゾーン

## SYNOPSISは,システムタイムゾーンを指定されたタイムゾーンに設定します.

## SYNTAXは,のシンタックスです.

### 名前 (デフォルト) 

```
Set-TimeZone [-Name] <String> [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Id でした.

```
Set-TimeZone -Id <String> [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject

```
Set-TimeZone [-InputObject] <TimeZoneInfo> [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## 記述は,

   `Set-TimeZone`cmdlet は,システムタイムゾーンを指定されたタイムゾーンに設定します.

## 例えは

### 例1: Idでタイムゾーンを設定する

この例では,ローカルコンピュータのタイムゾーンを UTCに設定します.

```powershell
Set-TimeZone -Id "UTC"
```

```Output
Id                         : UTC
DisplayName                : (UTC) Coordinated Universal Time
StandardName               : Coordinated Universal Time
DaylightName               : Coordinated Universal Time
BaseUtcOffset              : 00:00:00
SupportsDaylightSavingTime : False
```

### 例2: タイムゾーンを名前で設定する

この例では,ローカルコンピュータのタイムゾーンを UTCに設定します.

```powershell
Set-TimeZone -Name 'Coordinated Universal Time' -PassThru
```

前例で見たように,タイムゾーンの **Id** と **Name** は必ずしも一致しない. **Name** パラメータは **TimeZoneInfo** オブジェクトの **StandardName** または **DaylightName** 属性と一致しなければならない.

> [!NOTE] > タイムゾーン名々は,Windowsの文化設定に基づいて異なる可能性があります.この例では,システムに設定された>値が表示されます.`en-US` .

### 例3 - 可能な時間帯をすべてリストする

タイムゾーンIDの完全なリストは,次のコマンドを実行することによって得ることができます:

```powershell
Get-TimeZone -ListAvailable
```

###英語原文###
# Set-TimeZone

## SYNOPSIS
Sets the system time zone to a specified time zone.

## SYNTAX

### Name (Default)

```
Set-TimeZone [-Name] <String> [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### Id

```
Set-TimeZone -Id <String> [-PassThru] [-WhatIf] [-Confirm] [<CommonParameters>]
```

### InputObject

```
Set-TimeZone [-InputObject] <TimeZoneInfo> [-PassThru] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

The `Set-TimeZone` cmdlet sets the system time zone to a specified time zone.

## EXAMPLES

### Example 1: Set the time zone by Id

This example sets the time zone on the local computer to UTC.

```powershell
Set-TimeZone -Id "UTC"
```

```Output
Id                         : UTC
DisplayName                : (UTC) Coordinated Universal Time
StandardName               : Coordinated Universal Time
DaylightName               : Coordinated Universal Time
BaseUtcOffset              : 00:00:00
SupportsDaylightSavingTime : False
```

### Example 2: Set the time zone by name

This example sets the time zone on the local computer to UTC.

```powershell
Set-TimeZone -Name 'Coordinated Universal Time' -PassThru
```

As we saw in the previous example, the **Id** and the **Name** of the Time Zone do not always match.
The **Name** parameter must match the **StandardName** or **DaylightName** properties of the
**TimeZoneInfo** object.

> [!NOTE]
> The time zone names can vary based on the Culture settings in Windows. This example shows the
> values for a system set to `en-US`.

### Example 3 - List all available time zones

A full list of Time Zone IDs can be obtained by running the following command:

```powershell
Get-TimeZone -ListAvailable
```
