# Set-DhcpServerv6Binding を結びつけている

## SYNOPSIS は DHCP サーバサービスの IPv6 インターフェースの結合状態を設定します.

## SYNTAXは,のシンタックスです.

```
Set-DhcpServerv6Binding [-ComputerName <String>] [-BindingState] <Boolean> [-InterfaceAlias] <String[]>
 [-PassThru] [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## 記述 **Set-DhcpServerv6Binding** cmdlet は,コンピュータ上のダイナミックホスト設定プロトコル (DHCP) サーバサービスの指定された IPv6 インターフェースの結合状態を設定します.

## 例えは

### 例1: DHCPv6 サーバサービスをネットワークインターフェースに結びつけること```
PS C:\> Set-DhcpServerv6Binding -BindingState $True -InterfaceAlias "Wired Ethernet Connection"
```

この例ではDHCPv6サーバーサービスを,ワイヤードイーサネット接続と呼ばれるネットワークインターフェースに結びつける.

### 例2:ネットワークインターフェースからDHCPv6サーバーサービスを解除する```
PS C:\> Set-DhcpServerv6Binding -BindingState $False -InterfaceAlias "Wired Ethernet Connection"
```

この例では,DHCPv6サーバーサービスをワイヤードイーサネット接続と呼ばれるネットワークインターフェースから解約します.

###英語原文###
# Set-DhcpServerv6Binding

## SYNOPSIS
Sets the binding state for an IPv6 interface of the DHCP server service.

## SYNTAX

```
Set-DhcpServerv6Binding [-ComputerName <String>] [-BindingState] <Boolean> [-InterfaceAlias] <String[]>
 [-PassThru] [-CimSession <CimSession[]>] [-ThrottleLimit <Int32>] [-AsJob] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
The **Set-DhcpServerv6Binding** cmdlet sets the binding state for the specified IPv6 interface of the Dynamic Host Configuration Protocol (DHCP) server service on the computer.

## EXAMPLES

### Example 1: Bind the DHCPv6 server service to a network interface
```
PS C:\> Set-DhcpServerv6Binding -BindingState $True -InterfaceAlias "Wired Ethernet Connection"
```

This example binds the DHCPv6 server service to the network interface named Wired Ethernet Connection.

### Example 2: Unbind the DHCPv6 server service from a network interface
```
PS C:\> Set-DhcpServerv6Binding -BindingState $False -InterfaceAlias "Wired Ethernet Connection"
```

This example unbinds the DHCPv6 server service from the network interface named Wired Ethernet Connection.
