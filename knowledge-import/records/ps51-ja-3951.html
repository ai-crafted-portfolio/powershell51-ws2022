# Write-Debug を書き直す

## SYNOPSISはコンソールにデバッグメッセージを送信します.

## SYNTAXは,のシンタックスです.

```
Write-Debug [-Message] <String> [<CommonParameters>]
```

## 記述は,

   `Write-Debug`cmdlet は,スクリプトやコマンドからホストにデバッグメッセージを書きます.

デフォルトではデバッグメッセージがコンソールで表示されないが,デバッグパラメータまたは  を使って表示できます.`$DebugPreference`変数です.

## 例えは

### 例1: $DebugPreference を理解する

この例ではデバッグメッセージが書かれています.

```powershell
Write-Debug "Cannot open file."
```

のデフォルト値は`$DebugPreference`** isSilentlyContinue**. したがって,メッセージはコンソールで表示されない.

### 例2:$DebugPreferenceの値を変更する

この例では,値を変えた結果が示されています.`$DebugPreference`まず,変数の現在の値を表示します.`$DebugPreference`誤差メッセージを書こうとする.その後,値を変更します.`$DebugPreference`** toContinue**で,デバッグメッセージが表示される.

```
PS> $DebugPreference
SilentlyContinue
PS> Write-Debug "Cannot open file."
PS>
PS> $DebugPreference = "Continue"
PS> Write-Debug "Cannot open file."
DEBUG: Cannot open file.
```

に関する詳細については,`$DebugPreference`[about_Preference_Variables] ((/powershell/module/Microsoft.PowerShell.Core/About/about_Preference_Variables) を参照してください.

### 例3:$DebugPreferenceを覆すためにデバッグパラメータを使用します.

   `Test-Debug`函数が書き出すのは,  の値です.`$DebugPreference`この例では,デバッグパラメータを使用して,変数を覆す.`$DebugPreference`値.

```powershell
function Test-Debug {
    [CmdletBinding()]
    param()
    Write-Debug ('$DebugPreference is ' + $DebugPreference)
    Write-Host ('$DebugPreference is ' + $DebugPreference)
}
```

```
PS> Test-Debug
$DebugPreference is SilentlyContinue

PS> Test-Debug -Debug
DEBUG: $DebugPreference is Inquire

Confirm
Continue with this operation?
[Y] Yes  [A] Yes to All  [H] Halt Command  [?] Help (default is "Y"):
$DebugPreference is Inquire
PS> $DebugPreference
SilentlyContinue
```

の値が値すると注意してください.`$DebugPreference`Debug パラメータを使用すると変更されます.この変更は関数の範囲にのみ影響します.関数外では値が影響されません.

> [!NOTE] > の値が値上がりすると`$DebugPreference`** isInquire**では,PowerShellで実行を停止し,実行が継続すべきかどうか尋ねます.

**Debug**の共通パラメータについての詳細については, [about_CommonParameters] を参照してください.https://go.microsoft.com/fwlink/?LinkID=113216) でした.

###英語原文###
# Write-Debug

## SYNOPSIS
Writes a debug message to the console.

## SYNTAX

```
Write-Debug [-Message] <String> [<CommonParameters>]
```

## DESCRIPTION

The `Write-Debug` cmdlet writes debug messages to the host from a script or command.

By default, debug messages are not displayed in the console, but you can display them by using the
**Debug** parameter or the `$DebugPreference` variable.

## EXAMPLES

### Example 1: Understand $DebugPreference

This example writes a debug message.

```powershell
Write-Debug "Cannot open file."
```

The default value of `$DebugPreference` is **SilentlyContinue**. Therefore, the message is not
displayed in the console.

### Example 2: Change the value of $DebugPreference

This example shows the effect of changing the value of the `$DebugPreference` variable. First, we
display the current value of `$DebugPreference` and attempt to write a debug message. Then we change
the value of `$DebugPreference` to **Continue**, which allows debug messages to be displayed.

```
PS> $DebugPreference
SilentlyContinue
PS> Write-Debug "Cannot open file."
PS>
PS> $DebugPreference = "Continue"
PS> Write-Debug "Cannot open file."
DEBUG: Cannot open file.
```

For more information about `$DebugPreference`, see
[about_Preference_Variables](/powershell/module/Microsoft.PowerShell.Core/About/about_Preference_Variables).

### Example 3: Use the Debug parameter to override $DebugPreference

The `Test-Debug` function writes the value of the `$DebugPreference` variable to the PowerShell host
and to the Debug stream. In this example, we use the **Debug** parameter to override the
`$DebugPreference` value.

```powershell
function Test-Debug {
    [CmdletBinding()]
    param()
    Write-Debug ('$DebugPreference is ' + $DebugPreference)
    Write-Host ('$DebugPreference is ' + $DebugPreference)
}
```

```
PS> Test-Debug
$DebugPreference is SilentlyContinue

PS> Test-Debug -Debug
DEBUG: $DebugPreference is Inquire

Confirm
Continue with this operation?
[Y] Yes  [A] Yes to All  [H] Halt Command  [?] Help (default is "Y"):
$DebugPreference is Inquire
PS> $DebugPreference
SilentlyContinue
```

Notice that the value of `$DebugPreference` changes when you use the **Debug** parameter. This
change only affects the scope of the function. The value is not affected outside the function.

> [!NOTE]
> When the value of `$DebugPreference` is **Inquire**, PowerShell halts execution to ask if
> execution should continue.

For more information about the **Debug** common parameter, see
[about_CommonParameters](https://go.microsoft.com/fwlink/?LinkID=113216).

## PARAMETERS

### -Message

Specifies the debug message to send to the console.

```yaml
Type: System.String
Parameter Sets: (All)
Aliases: Msg

Required: True
Position: 0
Default value: None
Accept pipeline input: True (ByValue)
Accept wildcard characters: False
```

### CommonParameters

This cmdlet supports the common parameters: -Debug, -ErrorAction, -ErrorVariable,
-InformationAction, -InformationVariable, -OutVariable, -OutBuffer, -PipelineVariable, -Verbose,
-WarningAction, and -WarningVariable. For more information, see
[about_CommonParameters](https://go.microsoft.com/fwlink/?LinkID=113216).

## INPUTS

### System.String

You can pipe a string that contains a debug message to this cmdlet.

## OUTPUTS

### None

This cmdlet returns no output. It only writes to the debug stream.
