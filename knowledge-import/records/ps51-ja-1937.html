# Disable-NetAdapterChecksumOffload  を無効にすると

## SYNOPSISは,ネットワークアダプターの選択したチェックサムをオフロードする機能を無効にします.

## SYNTAXは,のシンタックスです.

```

## 記述 **Disable-NetAdapterChecksumOffload** cmdlet はネットワークアダプターの選択したチェックサムオフロードを無効化します.指定された場合,IPv4,TCPv4,およびTCPv6チェックサムを無効化できます.これらのパラメータのうちのいずれもこのCMdletに転送されない場合,デフォルトではこのアダプターのチェックサムはすべて無効化されます.物理的なネットワークアダプターは,チェックサムオフロードの種類があり,チェックサム計算はメインプロセッサではなくネットワークアダプターで発生します. これによりプロセッサの利用が減少し,ネットワーク[U+541E]吐量を増加させることができます.このCMdlet はIPv4,TCPv4,TCPv6,UDPv4およびUDPv6を含むさまざまなチェックサムオフロード設定を無効化します.側スケーリング (RSS),セグメント協調化 (RSC) や大きな送信オフロード (LSO) を含むタテレスオフロード.

## 例えは

### 例1:すべてのネットワークアダプターでTCP/IPv6チェックサムオフロードを無効にし,再起動します.```
PS C:\> Disable-NetAdapterChecksumOffload -Name "*" -TcpIPv6
```

このコマンドは,すべてのネットワークアダプターでTCP/IPv6チェックサムオフロードを無効にし,ネットワークアダプターを再起動します.

# Disable-NetAdapterChecksumOffload

## SYNOPSIS
Disables the selected checksum offloads on the network adapter.

## SYNTAX

 [-Confirm] [<CommonParameters>]

## DESCRIPTION
The **Disable-NetAdapterChecksumOffload** cmdlet disables the selected checksum offloads on the network adapter.
When specified, IPv4, TCPv4, and TCPv6 checksums can be disabled.
If none of these parameters are passed into this cmdlet, then by default all of the checksums for this adapter are disabled.
Physical network adapters have various checksum offloads in which the checksum calculations occur in the network adapter and not in the main processor.
This reduces processor utilization and can increase network throughput.
This cmdlet disables the various checksum offload settings, including IPv4, TCPv4, TCPv6, UDPv4, and UDPv6.
Disabling checksum offload will also disable other stateless offloading including Receive Side Scaling (RSS), Receive Segment Coalescing (RSC) and Large Send Offload (LSO).

## EXAMPLES

### Example 1: Disable TCP/IPv6 checksum offload on all network adapters then restart them
```
PS C:\> Disable-NetAdapterChecksumOffload -Name "*" -TcpIPv6
```

This command disables TCP/IPv6 checksum offload on all network adapters and restarts the network adapters.
