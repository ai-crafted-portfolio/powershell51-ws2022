# Get-MpThreat を受け入れる

## SYNOPSISは,コンピュータで検出された脅威の履歴を取得します.

## SYNTAX 

### デフォルトセット (デフォルト) 

```
Get-MpThreat [<CommonParameters>]
```

### バイId

```
Get-MpThreat
 [-AsJob]
 [-CimSession <CimSession[]>]
 [-ThreatID <Int64[]>]
 [-ThrottleLimit <Int32>]
 [<CommonParameters>]
```

   `Get-MpThreat`cmdlet は,Windows Defender がコンピュータで検出した脅威の履歴を取得します.

```powershell
PS C:\> Get-MpThreat -ThreatID 1994
```

このコマンドは,ID 1994を持つローカルコンピュータの脅威の歴史を入手します.

# Get-MpThreat

## SYNOPSIS
Gets the history of threats detected on the computer.

## SYNTAX

### DefaultSet (Default)

```
Get-MpThreat [<CommonParameters>]
```

### ById

```
Get-MpThreat
 [-AsJob]
 [-CimSession <CimSession[]>]
 [-ThreatID <Int64[]>]
 [-ThrottleLimit <Int32>]
 [<CommonParameters>]
```

## DESCRIPTION

The `Get-MpThreat` cmdlet gets the history of threats that Windows Defender detected on the
computer.

## EXAMPLES

### Example 1: Get the history of a detected threat

```powershell
PS C:\> Get-MpThreat -ThreatID 1994
```

This command gets the history of the threat on the local computer that has the ID 1994.
