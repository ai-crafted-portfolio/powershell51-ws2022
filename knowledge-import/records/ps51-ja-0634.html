# Get-MpPreference を使って

## シノプシスです.

Windows Defenderの設定と設定を返します.

## SYNTAX 

```
Get-MpPreference
 [-AsJob]
 [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>]
 [<CommonParameters>]
```

## 記述は,

   `Get-MpPreference`このcmdletが取り戻す設定についての詳細については, [Windows Defender Preferences Class] (/previous-versions/windows/desktop/legacy/dn455323(v=vs.85) を参照してください).

## 例えは,

### 例1:すべての設定を表示する

```powershell
Get-MpPreference
```

この例では,Windows Defenderのすべての設定を返します.

### 例2:スケジュールされたスキャン日を見る

```powershell
Get-MpPreference | Format-List ScanScheduleDay
```

この例では,ScanScheduleDay**設定の現在の値を返します.

###英語原文###
# Get-MpPreference

## SYNOPSIS

Returns settings and configuration for Windows Defender.

## SYNTAX

```
Get-MpPreference
 [-AsJob]
 [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>]
 [<CommonParameters>]
```

## DESCRIPTION

The `Get-MpPreference` cmdlet returns settings for Windows Defender. For more
information about the settings that this cmdlet retrieves, see
[Windows Defender Preferences Class](/previous-versions/windows/desktop/legacy/dn455323(v=vs.85)).

## EXAMPLES

### Example 1: View all settings

```powershell
Get-MpPreference
```

This example returns all settings for Windows Defender.

### Example 2: View the scheduled scan day

```powershell
Get-MpPreference | Format-List ScanScheduleDay
```

This example returns the current value of the **ScanScheduleDay** setting.

complete.

The cmdlet immediately returns an object that represents the job and then displays the command

`*-Job` cmdlets. To get the job results, use the
[Receive-Job](https://go.microsoft.com/fwlink/?LinkID=113372) cmdlet.

For more information about Windows PowerShell background jobs, see
[about_Jobs](https://go.microsoft.com/fwlink/?LinkID=113251).

computer. The throttle limit applies only to the current cmdlet, not to the session or to the
computer.
