# PSScheduledJob Module

## 記述 記述

PSScheduledJob モジュールは,Windows PowerShellでスケジュールされた作業を管理するcmdletsとプロバイダーを含んでいます.

## PSScheduledJob Cmdlets

### [JobTrigger追加](Add-JobTrigger.md) は,予定された仕事への求人誘因を追加します.

### [Disable-JobTrigger] (Disable-JobTrigger.md) は,予定された仕事のジョブトリガーを無効にする.

### [Disable-ScheduledJob.md] は,予定された仕事を無効にする.

### [Enable-JobTrigger](Enable-JobTrigger.md) は,予定された仕事の求人誘因を有効にする.

### [Enable-ScheduledJob.md]は,予定された仕事を有効にする.

### [Get-JobTrigger] (Get-JobTrigger.md) は,予定された仕事の仕事引き出物を取得します.

### [Get-ScheduledJob.md]は,ローカルコンピュータでスケジュールされた仕事を取得します.

### [Get-ScheduledJobOption] (Get-ScheduledJobOption.md) は,予定職の求人オプションを入手する.

### [New-JobTrigger] (New-JobTrigger.md) は,予定された仕事のための求人誘発器を作成します.

### [New-ScheduledJobOption] (New-ScheduledJobOption.md) は,予定された仕事に対する高度なオプションを含むオブジェクトを作成します.

### [Register-ScheduledJob.md]は,予定された仕事を作成します.

### [Remove-JobTrigger](Remove-JobTrigger.md) 予定された仕事からジョブトリガーを削除します.

### [Set-JobTrigger](Set-JobTrigger.md) 予定された仕事の仕事の誘導機を変更します.

### [セット・スケジュールジョブ](セット・スケジュールジョブ.md) 予定の職位を変更します.

### [Set-ScheduledJobOption](Set-ScheduledJobOption.md) は,予定された仕事の職種を変更します.

### [Unregister-ScheduledJob.md] 地元のコンピュータで予定されている仕事を削除します.
###英語原文###
# PSScheduledJob Module

## Description

The PSScheduledJob module contains cmdlets and providers that manage scheduled jobs in Windows
PowerShell.

## PSScheduledJob Cmdlets

### [Add-JobTrigger](Add-JobTrigger.md)
Adds job triggers to scheduled jobs.

### [Disable-JobTrigger](Disable-JobTrigger.md)
Disables the job triggers of scheduled jobs.

### [Disable-ScheduledJob](Disable-ScheduledJob.md)
Disables a scheduled job.

### [Enable-JobTrigger](Enable-JobTrigger.md)
Enables the job triggers of scheduled jobs.

### [Enable-ScheduledJob](Enable-ScheduledJob.md)
Enables a scheduled job.

### [Get-JobTrigger](Get-JobTrigger.md)
Gets the job triggers of scheduled jobs.

### [Get-ScheduledJob](Get-ScheduledJob.md)
Gets scheduled jobs on the local computer.

### [Get-ScheduledJobOption](Get-ScheduledJobOption.md)
Gets the job options of scheduled jobs.

### [New-JobTrigger](New-JobTrigger.md)
Creates a job trigger for a scheduled job.

### [New-ScheduledJobOption](New-ScheduledJobOption.md)
Creates an object that contains advanced options for a scheduled job.

### [Register-ScheduledJob](Register-ScheduledJob.md)
Creates a scheduled job.

### [Remove-JobTrigger](Remove-JobTrigger.md)
Delete job triggers from scheduled jobs.

### [Set-JobTrigger](Set-JobTrigger.md)
Changes the job trigger of a scheduled job.

### [Set-ScheduledJob](Set-ScheduledJob.md)
Changes scheduled jobs.

### [Set-ScheduledJobOption](Set-ScheduledJobOption.md)
Changes the job options of a scheduled job.

### [Unregister-ScheduledJob](Unregister-ScheduledJob.md)
Deletes scheduled jobs on the local computer.
