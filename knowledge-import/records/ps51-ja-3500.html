# Microsoft.PowerShell.Archive Module について

## 記述 記述

このセクションは,PowerShell Microsoft.PowerShell.Archive モジュールでインストールされているcmdletのサポートトピックが含まれています.アーカイブモジュールには,アーカイブまたはZIPファイルを作成し,抽出できるようにするcmdletが含まれています.

## Microsoft.PowerShell.Archive Cmdlets を表示する

### [Compress-Archive](Compress-Archive.md) 

指定したファイルやディレクトリから圧縮されたアーカイブ,またはジップファイルを作成します.

### [Expand-Archive](Expand-Archive.md) 

指定されたアーカイブ (zipped) ファイルからファイルを抽出します.
###英語原文###
# Microsoft.PowerShell.Archive Module

## Description

This section contains the help topics for the cmdlets that are installed with the PowerShell
Microsoft.PowerShell.Archive module. The Archive module contains cmdlets that let you create and
extract archive or ZIP files.

## Microsoft.PowerShell.Archive Cmdlets

### [Compress-Archive](Compress-Archive.md)

Creates a compressed archive, or zipped file, from specified files and directories.

### [Expand-Archive](Expand-Archive.md)

Extracts files from a specified archive (zipped) file.
