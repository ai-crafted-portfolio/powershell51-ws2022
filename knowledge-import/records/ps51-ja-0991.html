# Get-DnsServerTrustPointに提供される

## SYNOPSISは,DNSサーバーで信頼ポイントを獲得します.

## SYNTAX 

```
Get-DnsServerTrustPoint [[-Name] <String[]>] [-ComputerName <String>] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## 記述 **Get-DnsServerTrustPoint** cmdlet は,ドメイン名システム (DNS) サーバで1つ以上の信頼ポイントを取得します.信頼ポイントの名前を指定していない場合は,すべての信頼ポイントがリストされます.

## 例えは,

### 例1: DNS サーバの信頼ポイントのリストを取得する```
PS C:\> Get-DnsServerTrustPoint
```

このコマンドは,ローカルDNSサーバーのすべての信頼ポイントのリストを取得します.

# Get-DnsServerTrustPoint

## SYNOPSIS
Gets trust points on a DNS server.

## SYNTAX

```
Get-DnsServerTrustPoint [[-Name] <String[]>] [-ComputerName <String>] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## DESCRIPTION
The **Get-DnsServerTrustPoint** cmdlet gets one or more trust points on a Domain Name System (DNS) server.
If you do not specify a trust point name, all trust points are enumerated.

## EXAMPLES

### Example 1: Get a list of trust points on a DNS server
```
PS C:\> Get-DnsServerTrustPoint
```

This command gets a list of all trust points on the local DNS server.
