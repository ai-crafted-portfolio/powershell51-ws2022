# 退休日程を予定する

## SYNOPSIS は,コンピュータで定義されたデデプリカレーションの仕事のスケジュールを返します.

## SYNTAXは,のシンタックスです.

```
Get-DedupSchedule [[-Name] <String[]>] [-Type <Type[]>] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## 記述は,

   `Get-DedupSchedule`cmdlet では,コンピュータで定義された **DeduplicationJobSchedule** オブジェクトが返されます.

このcmdletを実行するには,管理者として実行する**オプションで Windows PowerShell(R) を起動する必要があります.

## 例えは

### 例1: 活発なスケジュールを取得する

```powershell
Get-DedupSchedule
```

このコマンドは,現在アクティブのデータデプリカレーションスケジュールオブジェクトを返します.`New-DedupSchedule`cmdletです.

### 例2:最適化仕事のためのスケジュールを取得する

```powershell
Get-DedupSchedule -Type Optimization
```

このコマンドは,最適化作業のためのすべてのデータデプリカレーションスケジュールを返します.

### 例3: 名前名スケジュールを取得する

```powershell
Get-DedupSchedule -Name MySchedule
```

このコマンドはMyScheduleというデータデプリカレーションスケジュールを返します.

# Get-DedupSchedule

## SYNOPSIS
Returns the deduplication job schedule defined on the computer.

## SYNTAX

```
Get-DedupSchedule [[-Name] <String[]>] [-Type <Type[]>] [-CimSession <CimSession[]>]
 [-ThrottleLimit <Int32>] [-AsJob] [<CommonParameters>]
```

## DESCRIPTION

The `Get-DedupSchedule` cmdlet returns the **DeduplicationJobSchedule** objects defined on the
computer.

To run this cmdlet, you must start Windows PowerShell(R) with the **Run as administrator** option.

## EXAMPLES

### Example 1: Get active schedules

```powershell
Get-DedupSchedule
```

This command returns the currently active data deduplication schedule objects created using the
`New-DedupSchedule` cmdlet.

### Example 2: Get schedules for optimization jobs

```powershell
Get-DedupSchedule -Type Optimization
```

This command returns all data deduplication schedules for optimization jobs.

### Example 3:  Get a named schedule

```powershell
Get-DedupSchedule -Name MySchedule
```

This command returns the data deduplication schedule named MySchedule.
