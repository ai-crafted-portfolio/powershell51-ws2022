# Get-WmsSystem

## SYNOPSIS
Gets MultiPoint Server system information.

## SYNTAX

```
Get-WmsSystem [-Server <String>] [<CommonParameters>]
```

## DESCRIPTION
The **Get-WmsSystem** cmdlet gets Windows MultiPoint Server system information.
