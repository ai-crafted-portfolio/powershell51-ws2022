運用前提

1. `record viewer` で exact stanza を開き、各 record を `records\PS51-WS2022-2026-xxxx.txt` として UTF-8 保存します。

2. 下の `ファイル` セクションから `PS51-WS2022.txt` と補助スクリプトをコピーし、同名でローカル保存します。

3. `build_powershell51_bundle.ps1` で copied record 群を CP932 bundle に連結し、`check` / `install` を実行します。

4. `split_powershell51_bundle.ps1` は bundle を record 単位に戻したい場合だけ使います。

01

record を保存

下の viewer は bundle 元データから切り出した exact stanza を表示します。必要な record を開き、ファイル名ごとコピーしてローカルの `records\` へ保存します。

02

補助ファイルを保存

形式定義、batch、PowerShell スクリプトは個別の code block で提供します。ダウンロードではなく、そのままコピーして同名ファイルに貼り付けます。

03

bundle を生成して投入

UTF-8 保存した record 群から `build_powershell51_bundle.ps1` が CP932 bundle を生成します。生成後は既存の `check` / `install` で KnowledgeMgr へ投入します。
